语言： English · 简体中文 · 繁體中文 · 日本語 · Polski · Français · Deutsch · 한국어 · Українська

FigmaMCP 是一个免费的本地工具，让 Claude Code 或 Codex 读取并编辑你在 Figma 桌面版中打开的文件。它通过 Figma 的插件 API 在你的 Mac 上运行，所以没有调用次数需要盯着。

实际效果

它能做什么

用日常语言告诉 Agent 你想要什么。它先读取打开文件的结构，再直接在这个文件里改，你可以看着改动发生。

读取

页面、画框、图层、文字、组件、变量和样式 —— 来自你眼前这个文件。

编辑

创建和修改画框、文字、形状、组件和实例、自动布局、填充、描边和效果。

批量应用

一次请求里重命名、改样式或改写很多图层，例如把所有提到旧产品名的文字图层一起改掉。

保持在边界内

每次编辑都必须准确指明目标；批量编辑里只要有一项无效，就一项都不会改；插件里的一个开关可以让文件变成只读。

怎么用

  1. 下载并打开 App

    下载 Mac 版 FigmaMCP 并打开它。它常驻在菜单栏。

  2. 点击 Add to Figma

    只有 Figma 正在运行且还没装插件时，才会重启一次。你也可以允许“辅助功能”权限，这样 FigmaMCP 能替你的 Agent 打开插件。

  3. 让 Agent 去改

    让 Claude Code 或 Codex 修改你打开的文件。不需要导入任何东西，不需要贴代码，也不需要选端口。

你应该先知道的事

  • 目前仅支持 macOS。
  • 需要 Figma 桌面版，不能在浏览器里运行。
  • FigmaMCP 不在 Figma Community 里，Mac App 会替你安装插件。
  • 如果不允许“辅助功能”，请在每个文件里手动打开一次插件（Plugins、Development、FigmaMCP），并在 Agent 编辑期间保持它打开。
  • Dev Mode 等属于 Figma 本身的功能不包含在内。

常见问题

FigmaMCP 真的免费吗？
是的。免费，没有付费档。它不调用 Figma 托管的 MCP 服务器，所以 Figma 按座位计算的调用限制不适用于它。你打开的文件仍然受你自己的 Figma 方案和 Figma 条款约束。
它和 Figma 官方 MCP 服务器有什么不同？
Figma 官方服务器由 Figma 自己提供，可配合许多 MCP 客户端使用。在较低档的方案上，它的读取调用有上限，画布写入还处于 beta，并且在草稿之外需要 Full 席位。FigmaMCP 在你的 Mac 上运行，通过你已打开文件里的插件工作，不需要 API 令牌，也没有调用配额。它适用于 Claude Code 和 Codex，仅支持 macOS。详见完整对比。
两个人同时打开同一个文件，Agent 编辑的是谁的 Figma？
是 Agent 所在那台 Mac 上的 Figma 桌面版。Agent 与该应用中的插件通信，所以是以那个人的身份编辑，他需要有该文件的编辑权限。其他人会像看到任何其他编辑一样实时看到改动。如果两个人在同一时刻修改同一个图层，由 Figma 自己的多人同步来解决：修改不同属性时两处改动都保留，修改同一属性时以最后一次改动为准。FigmaMCP 自己不增加任何合并步骤。
支持 Windows 或 Linux 吗？
暂时不支持。FigmaMCP 目前仅支持 macOS。
需要 Figma API 令牌吗？
不需要。FigmaMCP 通过插件 API 和你 Mac 上的 Figma 桌面版通信，没有访问令牌需要创建或粘贴。
为什么插件不在 Figma Community 里？
FigmaMCP 在 Figma Community 之外分发。你不需要手动安装：Mac App 会替你把它注册到 Figma，之后它会出现在 Plugins、Development 下。
支持哪些 Agent？
Claude Code 和 Codex 是经过测试的目标，Mac App 会替你连接它们。
Agent 会不会毁掉我的文件？
改动只会发生在插件已打开、且“AI can edit this file”开关为开的文件里；关掉开关，AI 就只能读取。每次编辑都必须准确指明目标图层，批量编辑在改动前会先检查。它仍然是一个编辑工具：请像检查同事的工作一样检查结果，并用好 Figma 的版本历史。
它会向 Figma 的服务器发请求吗？
不会。FigmaMCP 不调用 Figma 的服务器或 REST API。你的 Agent 和本地的 MCP 服务器通信，MCP 服务器再通过 localhost 和 Figma 桌面版里的插件通信，插件通过 Plugin API 在 App 内读取和编辑文件。你的改动之后会像你自己编辑一样，通过 App 的正常同步到达 Figma 的云端。插件自身发出的请求不带文件内容：每次插件启动时，会向 figmamcp.dev 和 Google Analytics 发送一次加载计数，带上插件版本和一个随机安装 ID；还会把按工具名统计的调用次数批量发送给 figmamcp.dev，不带任何内容。
我的设计会离开我的电脑吗？
FigmaMCP 本身不会把文件内容发送到任何地方。不过你的 Agent 会读取 FigmaMCP 返回的内容，并按它自己模型服务商的条款发送出去，详见隐私页面。
这是 Figma 官方做的吗？
不是。FigmaMCP 与 Figma, Inc. 没有关联，也未获得其认可。FigmaMCP 是 Neo Product LLC 的 figma-edit-mcp 的分支。

校验下载

App 需要 macOS 14 或更高版本，支持 Intel 和 Apple 芯片的 Mac。磁盘映像约 155 MB。如果 /download 很慢或打不开，请从 GitHub 发布页下载 FigmaMCP.dmg，或用固定链接：curl -L -O https://github.com/MrCoder/figmamcp-releases/releases/latest/download/FigmaMCP.dmg。发布页在每个文件旁边显示一个 sha256: 值，把它和你下载的文件比较：

shasum -a 256 ~/Downloads/FigmaMCP.dmg

两个值不一致时，删除文件并重新下载。

安装程序会改动什么

App 的清单只写入下面这些位置，已经完成的步骤会跳过。

安装程序写入的文件和设置
位置内容
/Applications/FigmaMCP.appApp 本身。
~/.figmamcp/versions/<版本> 和 ~/.figmamcp/current每个版本的 MCP 服务器、中继、插件和 skill。current 是指向当前版本的符号链接。config.json 记录中继端口，logs/ 存放中继日志。
~/.claude.json用 claude mcp add 添加的用户级 MCP 条目 figmamcp。只在装了 Claude Code 时添加。
~/.codex/config.toml用 codex mcp add 添加的 MCP 条目 figmamcp。只在装了 Codex 时添加。
~/.claude/skills/figmamcp 和 ~/.codex/skills/figmamcpFigmaMCP skill，给 AI 看的使用说明。如果其中一个是指向别处的链接，就不会改动它。
~/Library/LaunchAgents/com.figmamcp.relay.plist登录时启动本地中继的 LaunchAgent。中继监听 localhost 的 3155 端口；被占用时改用 3156 到 3158 中第一个空闲端口。
Figma 的插件列表把 FigmaMCP 开发插件加入 ~/Library/Application Support/Figma/settings.json，原文件保存在旁边的 settings.json.figmamcp-backup。

旧的同类配置不会被改动。如果你以前装过 FigmaMCP 所派生的上游项目，它的 MCP 条目、中继和插件都保持原样。区分方法：FigmaMCP 的工具名以 mcp__figmamcp__ 开头，插件在 Plugins → Development → FigmaMCP；其他前缀的工具不属于 FigmaMCP。不想两个并存时，用 claude mcp list 或 codex mcp list 找到旧条目，再用对应的 mcp remove 删掉。

卸载或回退

回退到旧版本：从版本列表下载旧版 FigmaMCP.dmg，替换“应用程序”里的 App，打开它并按清单操作，然后重启 Claude Code 或 Codex。装过的旧版本保留在 ~/.figmamcp/versions 里。

卸载：先在 Figma 里选 Plugins → Development → Manage plugins in development，移除 FigmaMCP。然后在终端运行下面的命令。没有用某个 AI 就跳过对应的 claude 或 codex 那一行。最后两行会删除 App 和所有 FigmaMCP 版本，无法撤销。

osascript -e 'quit app "FigmaMCP"'
launchctl bootout gui/$(id -u)/com.figmamcp.relay
rm ~/Library/LaunchAgents/com.figmamcp.relay.plist
claude mcp remove figmamcp -s user
codex mcp remove figmamcp
rm -rf ~/.claude/skills/figmamcp ~/.codex/skills/figmamcp
rm -rf /Applications/FigmaMCP.app ~/.figmamcp

之后重启 Claude Code 或 Codex，让它不再加载这个工具。

隐私

网站和插件会统计使用情况：网站使用 Google Analytics，插件每次打开发送一个事件，只带插件版本号和一个随机的安装 ID；插件还会分批发送工具调用次数（按工具名统计成功和失败次数），不带文件名、文件密钥、图层名或设计内容。完整说明见隐私页。
