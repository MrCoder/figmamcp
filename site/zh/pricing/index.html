如何使用 FigmaMCP

没有东西要买，也不用注册。下面四步，从下载到拿到 Agent 对文件的第一个回答。

  1. 下载并打开 App。 下载 Mac 版 FigmaMCP，打开 FigmaMCP.dmg，把 App 拖进 Applications（应用程序），然后打开它。

  2. 点击 Add to Figma。 App 的检查清单会检查 Figma、Claude Code 和 Codex。点击 Add to Figma。只有 Figma 正在运行且缺少插件时，Figma 才会重启一次。

  3. 重启 Agent。 如果 Claude Code 或 Codex 正在运行，退出后重新启动，让它加载新工具。

  4. 在文件里打开插件。 在 Figma 桌面版中打开文件，然后选择 Plugins › Development › FigmaMCP。面板会显示已连接的文件。要让 Agent 编辑，面板里的 “AI can edit this file”（AI 可以编辑此文件）开关必须打开。

然后先让 Agent 读取一次。粘贴这句：“列出所选画框里的文字图层，以及它们的字体和字号。”读取不会改动文件，适合做第一次测试。

完整步骤见 5 分钟用 Claude Code 编辑 Figma 文件。

和 Figma 官方 MCP 服务器对比

Figma 官方的 MCP 服务器是托管服务，按席位和方案限制调用次数。FigmaMCP 的做法不同：Mac 上的本地服务器和 Figma 桌面版里的插件通信。它不调用 Figma 的 MCP 服务器，所以 Figma 的读取限额与它的工作方式无关。

写入是另一回事

Figma 表示，它的写入工具不计入这些读取限额。用 Figma 的服务器写入画布，需要 Professional 或更高的方案，并且要有编辑权限。Figma 称这项功能测试期间免费，之后计划按用量收费。详见 Figma 的 write to canvas 页面（2026 年 11 月 25 日核实），或我们的 Figma MCP write to canvas 页面（英文），那里把官方条款和本地方案放在一起。

所以官方服务器不只是读取限额的问题，我们也没有这样宣称。两个工具的工作方式不同，选适合你工作方式的那个。各方案的细节见 Figma MCP on the free plan、Figma MCP Starter plan limit 和 Figma MCP limit reached（均为英文）。

使用前须知

  • 目前仅支持 macOS。
  • 需要 Figma 桌面版，不能在浏览器中运行。
  • FigmaMCP 不在 Figma Community 上，由 Mac App 替你安装插件。
  • 如果不授予辅助功能权限，请在每个文件中打开一次插件（Plugins、Development、FigmaMCP），并在 Agent 编辑期间保持打开。
  • Figma 自身的功能（例如 Dev Mode）不包含在内。

FigmaMCP 是独立软件。你使用 Figma 桌面版时，仍受 Figma 条款约束。

常见问题

FigmaMCP 免费吗？
目前免费。不收费，不用注册，也不需要 API 令牌。以后我们可能会定价，不承诺永久免费。
Figma 官方的 MCP 服务器免费吗？
Figma 按席位和方案公布调用限额，并表示写入画布需要 Professional 或更高的方案和编辑权限，测试期间免费，之后计划按用量收费。最新条款请看上文链接的 Figma 页面。
Enterprise 方案用 Figma MCP 要花多少钱？
Figma 的 MCP 服务器包含在你的 Figma 方案里。Enterprise 方案不同的是读取限额：Full 或 Dev 席位每天最多 600 次、每分钟 20 次，View 或 Collab 席位每月 20 次（2026-11-22 核对 Figma 的页面）。写入工具不计入限额。各方案的完整限额见 Figma MCP 调用限额。FigmaMCP 在任何方案下都免费，没有调用配额。我们还没在 Enterprise 账号上测试过；关键是你的组织是否允许运行开发版插件，请先在一个文件上试。
Figma 的读取限额适用于 FigmaMCP 吗？
不适用。FigmaMCP 不调用 Figma 的 MCP 服务器，它通过你已经打开的桌面版里的 Plugin API 工作。
用 FigmaMCP 需要给 Figma 付费吗？
FigmaMCP 在 Figma 桌面版里运行一个开发版插件，所以关键在于你的账号能否在文件里运行开发版插件。我们没有测试过每一种方案。先在一个文件上试试。
