什么是 Figma MCP 服务器？

语言： English · 简体中文 · 日本語

Figma MCP 服务器是一个程序，给 Claude Code 这类 AI Agent 提供操作 Figma 的工具。接上之后，Agent 可以读取你的设计；有些服务器还能修改设计。MCP 是 Model Context Protocol（模型上下文协议）的缩写，是一种让 Agent 调用外部工具的开放协议。

工作原理

  1. 你向 Agent 提要求

    例如：“根据所选画框搭建这个页面。”

  2. Agent 调用一个工具

    MCP 服务器列出可用的工具，Agent 从中选一个。

  3. 服务器和 Figma 通信

    通过托管服务、桌面版、REST API 或插件。走哪条路，决定了服务器能做什么。

  4. 结果返回

    Agent 读取结果，再决定下一步。

在自己的文件上试试

想在真实文件上看到这四步，可以试试 FigmaMCP。它是一个免费的 Mac 插件服务器，安装大约需要五分钟。

  1. 下载并打开 App。 下载 Mac 版 FigmaMCP，打开 FigmaMCP.dmg，把 App 拖进 Applications（应用程序），然后打开它。

  2. 点击 Add to Figma。 App 的检查清单会检查 Figma、Claude Code 和 Codex。点击 Add to Figma。只有 Figma 正在运行且缺少插件时，Figma 才会重启一次。

  3. 重启 Agent。 如果 Claude Code 或 Codex 正在运行，退出后重新启动，让它加载新工具。

  4. 在文件里打开插件。 在 Figma 桌面版中打开文件，然后选择 Plugins › Development › FigmaMCP。面板会显示已连接的文件。要让 Agent 编辑，面板里的 “AI can edit this file”（AI 可以编辑此文件）开关必须打开。

然后先让 Agent 读取一次。粘贴这句：“列出所选画框里的文字图层，以及它们的字体和字号。”读取不会改动文件，适合做第一次测试。

完整步骤见 5 分钟用 Claude Code 编辑 Figma 文件。

FigmaMCP 属于哪一种

FigmaMCP 是一个免费的 Mac 插件服务器。它处理的是你在 Figma 桌面版里打开的文件，不需要 API 令牌，也不占用 Figma 的 MCP 调用限额。可以看看它的全部工具，或对比本地和远程服务器（均为英文）。

使用前须知

  • 目前仅支持 macOS。
  • 需要 Figma 桌面版，不能在浏览器中运行。
  • FigmaMCP 不在 Figma Community 上，由 Mac App 替你安装插件。
  • 如果不授予辅助功能权限，请在每个文件中打开一次插件（Plugins、Development、FigmaMCP），并在 Agent 编辑期间保持打开。
  • Figma 自身的功能（例如 Dev Mode）不包含在内。

常见问题

Figma MCP 服务器和 Figma 插件是一回事吗？
不是。插件在 Figma 里运行；MCP 服务器给 Agent 提供工具。FigmaMCP 两者都用：服务器对接 Agent，插件在 Figma 里执行操作。
Figma MCP 免费吗？
取决于服务器。Figma 自己的服务器按方案和席位限制调用。FigmaMCP 免费。详情见价格页面。
Agent 会把我的设计发给模型吗？
Agent 读到的内容会发给它自己的模型服务商，按该服务商的条款处理。FigmaMCP 不会把任何设计内容发给我们。
