Figma MCP without Dev Mode

Can you use a Figma MCP server without Dev Mode or a Dev seat? Figma’s remote MCP server is listed for all plans, and the pages we checked do not say that Dev Mode is required. Figma’s desktop MCP server does need a Dev or Full seat. This page lists what the official server needs for each seat, then describes a separate free local tool that works through your own Figma desktop app. Checked 2026-11-13.

Figma’s pages are the authority and they may change. The call limits apply to tools that read data from Figma. Figma says tools that write to Figma files are exempt from that read limit.

Dev seat and Dev Mode are different things

A Dev seat is a kind of paid seat. Dev Mode is a view inside Figma for inspecting designs. Figma’s docs tie the desktop MCP server to a Dev or Full seat. For the remote server, the docs we checked list the plan and the client, and they do not name Dev Mode as a requirement. If a message in your tool mentions a seat, compare it with the table above and with your own seat in Figma.

A separate free local tool

FigmaMCP is a free Mac app and it is not made by Figma. It works with Claude Code and Codex only. The Mac app adds a plugin to Figma and connects Claude Code and Codex, and it needs no API token.

FigmaMCP reads and edits the file you have open in the Figma desktop app, through a local server and that plugin. It does not depend on Dev Mode or on a Dev seat. You need whatever access you already have to the file in Figma, and edit access if you want your agent to edit. FigmaMCP has no call quota of its own.

There are guardrails. The plugin has an “AI can edit this file” switch. Each edit names its target layer. Errors come back in a structured form that your agent can read.

Download for Mac Version 0.1.25 macOS 14+ · Intel & Apple Silicon · ~155 MB

What you should know first

  • macOS only for now.
  • It needs the Figma desktop app. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin for you.
  • If you do not allow Accessibility, open the plugin once in each file (Plugins, Development, FigmaMCP) and leave it open while your agent edits.
  • Features that belong to Figma itself, such as Dev Mode, are not included.

Questions

Do I need Dev Mode to use the Figma MCP server?
The Figma pages we checked on 2026-11-13 do not say Dev Mode is required. They do say the desktop server requires a Dev or Full seat, and that the remote server is listed for all plans.
Do I need a Dev seat for the official server?
For the desktop server, yes: Figma says it requires a Dev or Full seat on Professional, Education, Organization, Government or Enterprise. For the remote server, Figma’s help guide lists all plans, and writing outside your drafts needs a Full seat.
How do I use FigmaMCP without Dev Mode?
Install the Mac app, open a file in the Figma desktop app, and start Claude Code or Codex. FigmaMCP works through a plugin in that app, so it does not depend on Dev Mode or a Dev seat. You need your existing access to the file, and edit access to edit it.
Does FigmaMCP include Dev Mode features?
No. Features that belong to Figma itself, such as Dev Mode, are not included. FigmaMCP is a separate tool, not made by Figma.
