Figma MCP local vs remote

A remote Figma MCP server runs on Figma’s side. A local one runs on your computer and works through the desktop app. Figma recommends its remote server for most users. Local plugin servers such as FigmaMCP suit a different need. Details are as of November 25, 2026.

Where your data goes with FigmaMCP

  • The agent, local server and plugin connect on your own computer. The relay between them listens on localhost only.
  • FigmaMCP sends no design content to us.
  • Your agent passes what it reads to its own model provider. See the privacy page.

How to choose

  • No desktop app, or not on a Mac: use Figma’s remote server.
  • A company rule needs Figma’s desktop server: use that, and note that it cannot edit.
  • On a Mac, and you want local editing with no token: use FigmaMCP.

What you should know first

  • macOS only for now.
  • It needs the Figma desktop app. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin for you.
  • If you do not allow Accessibility, open the plugin once in each file (Plugins, Development, FigmaMCP) and leave it open while your agent edits.
  • Features that belong to Figma itself, such as Dev Mode, are not included.

Questions

Is a local server more private?
The connection stays on your computer, but your agent still sends what it reads to its model provider. Check that provider's terms.
Can Figma's desktop server edit my file?
Figma's guide says it does not support writing to the canvas. Check the guide for changes.
Does FigmaMCP work without the internet?
No. Figma and your agent need their own connections.
