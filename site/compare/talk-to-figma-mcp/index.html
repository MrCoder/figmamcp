Talk to Figma MCP compared with FigmaMCP

Talk to Figma MCP is the cursor-talk-to-figma-mcp project by sonnylazuardi. It connects an AI agent to Figma through an MCP server, a WebSocket relay and a Figma plugin. FigmaMCP descends from that line of work via figma-edit-mcp, and is a free Mac app for Claude Code and Codex. If you search for talk to figma mcp plugin, claude or cursor, this page explains the differences. Facts about Talk to Figma MCP are from its README, checked 2026-11-13.

How they are related

FigmaMCP is a fork of figma-edit-mcp by Neo Product LLC. Notices in that project credit sonnylazuardi, so FigmaMCP descends from the Talk to Figma line of work via figma-edit-mcp. It is a separate project, with different setup and its own guardrails.

Which one to choose

  • Talk to Figma MCP: you want the original project, you use Cursor, or you are not on a Mac. You can read and change its code, and it lists read and write tools.
  • FigmaMCP: you use Claude Code or Codex on a Mac and want the setup done for you: no channel to join, no relay to start, no token.

With FigmaMCP, edits only happen where the plugin’s “AI can edit this file” switch is on. Each edit names its target layer, and the name must match. Failures return structured errors, and batches are checked before they run. FigmaMCP has no call quota of its own.

What you should know first

  • macOS only for now.
  • It needs the Figma desktop app. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin for you.
  • If you do not allow Accessibility, open the plugin once in each file (Plugins, Development, FigmaMCP) and leave it open while your agent edits.
  • Features that belong to Figma itself, such as Dev Mode, are not included.

Questions

Does Talk to Figma MCP work with Claude?
Its README names Claude Code among the agents it supports, next to Cursor. Source: the cursor-talk-to-figma-mcp README, checked 2026-11-13.
Do I need a channel code with FigmaMCP?
No. The Mac app connects Claude Code and Codex to the plugin, so there is no channel code to type.
Is FigmaMCP the same project as Talk to Figma MCP?
No. FigmaMCP is a fork of figma-edit-mcp, whose notices credit sonnylazuardi. It is a separate project.
Is FigmaMCP affiliated with Figma?
No. FigmaMCP is independent and is not endorsed by Figma, Inc.
