Figma MCP comparison

Start here if you are choosing how to connect Claude Code or Codex to Figma. FigmaMCP is one option: a free Mac app that reads and edits the file open in the Figma desktop app, with no call quota. The pages below compare it with Figma’s own MCP server, the REST API and other tools, and each one says when the other tool is the better pick.

How FigmaMCP comparisons are written

We follow three rules on these pages. Facts about another tool come from that tool’s own README or documentation, with the date we checked and a link, and they may change after that date. Each page says when the other tool is the better pick, not only when FigmaMCP is. And each page states FigmaMCP’s own limits plainly.

FigmaMCP limits to weigh

FigmaMCP works on macOS with Claude Code and Codex only, and needs the Figma desktop app. FigmaMCP is not on Figma Community; the Mac app installs the plugin for you. FigmaMCP does not include Dev Mode features. See Figma MCP without Dev Mode for what each seat needs and a local option.
