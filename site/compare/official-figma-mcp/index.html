Official Figma MCP compared with FigmaMCP

Figma’s official MCP server is first-party and has features FigmaMCP does not. FigmaMCP is a free local option for editing the file open on your Mac. FigmaMCP is not made by Figma. This comparison uses Figma’s docs as of November 25, 2026.

Figma desktop MCP server and com.figma.mcp/mcp

The Figma desktop MCP server runs through the Figma desktop app, in Dev Mode. It reads the design and does not edit the canvas. Figma’s remote server is the hosted one, and you may see it listed as com.figma.mcp/mcp. FigmaMCP is neither: it is a plugin server that reads and edits the file open on your Mac.

Which one to choose

  • Official server: you need Figma’s supported route, Dev Mode features, or a client other than Claude Code and Codex.
  • FigmaMCP: you use a Mac and want your agent to read and edit the open file, with no token and a read-only switch.

Download for Mac Version 0.1.25 macOS 14+ · Intel & Apple Silicon · ~155 MB

See also local and remote servers and other alternatives.

What you should know first

  • macOS only for now.
  • It needs the Figma desktop app. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin for you.
  • If you do not allow Accessibility, open the plugin once in each file (Plugins, Development, FigmaMCP) and leave it open while your agent edits.
  • Features that belong to Figma itself, such as Dev Mode, are not included.

Questions

Is FigmaMCP affiliated with Figma?
No. FigmaMCP is independent and is not endorsed by Figma, Inc.
Can I use both?
They are separate servers. Avoid having two tools edit the same file at once.
Does every Figma plan work with FigmaMCP?
FigmaMCP uses a development plugin in the desktop app. Whether your account can run one is up to Figma, and we have not tested every plan.
