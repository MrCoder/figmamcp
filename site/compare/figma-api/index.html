Figma MCP vs Figma API

Use the Figma REST API when you write your own scripts or server jobs. Use a Figma MCP server when you want an AI agent to work on a design for you. The two sit at different layers: the REST API is an HTTP interface with access tokens and rate limits, and some MCP servers call it underneath. FigmaMCP does not. It is a free Mac app that works through the Figma desktop app. Facts about the REST API are from Figma’s docs, checked 2026-11-13.

How the limits work

  • Figma says limits depend on “the seat type of the user,” the endpoint’s tier, and the location and plan of the resource.
  • Tracking differs by auth type: OAuth apps per user, plan and app; plan access tokens per token and plan; personal access tokens per user and plan.
  • The 429 response includes a Retry-After header and a rate-limit-type header that says whether the seat is low or high.

Which one to choose

  • REST API: you are building your own integration, a server job, or a pipeline that must run without a person at a Mac.
  • FigmaMCP: you want Claude Code or Codex to read and edit the file open on your Mac, with no token to create or store. Edits run only where the “AI can edit this file” switch is on.

An agent that reads through the REST API uses your seat’s limits. FigmaMCP has no call quota of its own, though Figma and your agent still need their own connections.

What you should know first

  • macOS only for now.
  • It needs the Figma desktop app. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin for you.
  • If you do not allow Accessibility, open the plugin once in each file (Plugins, Development, FigmaMCP) and leave it open while your agent edits.
  • Features that belong to Figma itself, such as Dev Mode, are not included.

Questions

Do I need an access token for FigmaMCP?
No. FigmaMCP works through a plugin in the Figma desktop app, so there is no API token to create.
What happens when I hit a REST API rate limit?
Figma says the endpoint returns a 429 error, with a Retry-After header that gives the wait in seconds. Source: Figma REST API rate-limit docs, checked 2026-11-13.
Does FigmaMCP have a call quota?
FigmaMCP sets no call quota. Figma and your agent still apply their own terms and limits.
Is the REST API the same as Figma's MCP server?
They are different products from Figma. This page covers the REST API; see the official MCP comparison for Figma's MCP server.
