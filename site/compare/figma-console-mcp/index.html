Figma Console MCP compared with FigmaMCP

Both tools let an agent read and change a Figma file through a plugin. They differ in setup and reach. Figma Console MCP, a project by southleft, has a wide tool set, works with many MCP clients and needs a Figma access token for local setups. FigmaMCP is a free Mac app for Claude Code and Codex, and it needs no token. Facts about Figma Console MCP come from its own README, checked 2026-11-13.

Which one to choose

  • Figma Console MCP: you use a client other than Claude Code or Codex, you are not on a Mac, or you want its larger tool set and cloud modes. Its README says remote SSE mode “Cannot create or modify designs,” so check which mode you need.
  • FigmaMCP: you use a Mac with Claude Code or Codex and want no API token, no call quota from FigmaMCP, and a per-file switch for edits.

Both approaches work with the Figma desktop app. FigmaMCP reads and edits through a local server and a plugin, so there is nothing to put in an environment variable. Each edit must name its target layer, and the name has to match, which stops an agent from changing the wrong layer by accident. Batches are validated before they run, and failures come back as structured errors your agent can act on.

If your team already uses Figma Console MCP and it works, there is no need to switch. Do not point two tools at the same file at once.

What you should know first

  • macOS only for now.
  • It needs the Figma desktop app. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin for you.
  • If you do not allow Accessibility, open the plugin once in each file (Plugins, Development, FigmaMCP) and leave it open while your agent edits.
  • Features that belong to Figma itself, such as Dev Mode, are not included.

Questions

Does Figma Console MCP need a token?
Its README says local setups need a Figma personal access token, set as FIGMA_ACCESS_TOKEN. FigmaMCP needs no API token. Source: the Figma Console MCP README, checked 2026-11-13.
Can Figma Console MCP edit a file?
Its README says it can create and modify designs in its local and cloud modes, and that the remote SSE mode cannot. Source: the Figma Console MCP README, checked 2026-11-13.
Which clients does FigmaMCP support?
Claude Code and Codex, on a Mac. Figma Console MCP lists more clients in its README.
Is FigmaMCP affiliated with southleft or Figma?
No. FigmaMCP is independent and is not endorsed by Figma, Inc.
