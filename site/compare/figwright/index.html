Figwright vs FigmaMCP

Figwright is a free two-way Figma MCP server, and FigmaMCP is a free Mac app that does a similar job. Both let an agent read and edit the file open in Figma desktop through a plugin on your machine. They differ in how you install them, what runs on your computer and how edits are limited. Facts about Figwright come from its GitHub README, checked 2026-11-20.

Where Figwright is better

  • You can read the code. Its source is public. FigmaMCP’s is not.
  • It may fit more machines. The README names no operating system limit, while FigmaMCP runs only on macOS. We have not verified Figwright on Windows or Linux.
  • Browser Figma. Its README diagram shows Figma in the desktop app or the browser. FigmaMCP needs the desktop app.
  • More tools and skills. The README lists 136 tools and installable skills for code from a design and for building a design.
  • More than one agent at a time. Each agent can work in its own file.

Where FigmaMCP is different

  • Setup. One Mac app, notarized by Apple, registers the plugin for you. There is no Node and no zip to unpack or import.
  • Edit limits. Each edit must name its target layer exactly. A bulk edit with one invalid item changes nothing. One switch in the plugin makes the file read-only.
  • No token. It needs no Figma API token.

Which one to choose

Choose Figwright if you want public code, you are not on a Mac, or you want its broader tool set and are comfortable with Node and importing a plugin by hand. Choose FigmaMCP if you use a Mac with Claude Code or Codex and want the shortest install and strict limits on what an edit can touch. Both are free, so you can try both on a copy of a file; avoid having two tools edit the same file at once.

What you should know first

  • macOS only for now.
  • It needs the Figma desktop app. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin for you.
  • If you do not allow Accessibility, open the plugin once in each file (Plugins, Development, FigmaMCP) and leave it open while your agent edits.
  • Features that belong to Figma itself, such as Dev Mode, are not included.

Questions

Is Figwright free?
Yes. Its README describes it as a free two-way Figma MCP server that runs on the free Figma tier. Source: the Figwright README, checked 2026-11-20. FigmaMCP is free too.
How do I install Figwright?
Its README has two steps: add a server entry for @figwright/mcp, launched with npx, to your MCP client, then download the plugin zip from the latest GitHub release and import its manifest in the Figma desktop app. It needs Node.js 20.19+ or 22.12+. Source: the Figwright README, checked 2026-11-20.
Does Figwright work on Windows or Linux?
Its README states no operating system limit, says the Figma desktop app is needed to import the plugin, and shows Figma in the desktop app or the browser. We have not tested it on Windows or Linux. FigmaMCP is macOS only. Checked 2026-11-20.
Is FigmaMCP open to read like Figwright?
No. Figwright’s source is public. FigmaMCP’s source code is private; the built app and its releases are public.
Is FigmaMCP affiliated with Figwright or Figma?
No. FigmaMCP is independent and is not endorsed by Figma, Inc.
