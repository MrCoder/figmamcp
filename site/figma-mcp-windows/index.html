Figma MCP on Windows

FigmaMCP is macOS only for now. There is no Windows or Linux build of the FigmaMCP app. We have not tested FigmaMCP in WSL or a virtual machine, and we will not guess. If you are on Windows, pick one of the other Figma MCP options below.

What FigmaMCP does on Windows

FigmaMCP does not run on Windows today. The FigmaMCP Mac app is a macOS app. Its installer writes to macOS locations, such as /Applications, a LaunchAgent in ~/Library/LaunchAgents and Figma’s settings in ~/Library/Application Support/Figma. The table lists what we can say and what we cannot.

What to expect if you pick another option

FigmaMCP has a design that other options do not share. It has no call quota of its own, and it needs no Figma API token. Its plugin edits only where the AI can edit this file switch is on, and each edit names its target layer. If you leave FigmaMCP, you leave those rules behind. Read the guardrails of the option you choose. See the official server compared and Figma Console MCP compared for the facts we checked.

If you also have a Mac

FigmaMCP works on a Mac with the Figma desktop app and either Claude Code or Codex. If you have access to a Mac, the Mac app installs the plugin and connects your agent in one checklist. See setup on Mac.

Ask for Windows
