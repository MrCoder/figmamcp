Figma MCP rate limit by plan

Figma’s own MCP server limits how many calls an account can make. The limit applies to tools that read data from Figma. Some tools are exempt, including tools that write to Figma files. This page lists the limits by plan as Figma publishes them, checked 2026-11-22, and says what that means when an agent works on a design.

What counts and what does not

Which Figma MCP tools count against the limit
Kind of toolCounts against the limitExamples
Reads data from FigmaYesget_design_context, get_metadata, get_screenshot
Writes to Figma filesNo, exemptTools that write to Figma files; Figma’s page names add_code_connect_map, create_new_file and generate_figma_design as exempt, and also whoami, which reads your account details

Figma also says that actions which use Figma AI credits, such as generating images or sending prompts to Figma Make, do not count toward MCP rate limits. The checker below lists every tool.

Writing to the canvas has its own terms, which are separate from the rate limit: see write to canvas for plan and edit access.

What this means in practice

  • The part of an agent’s work that meets the cap is looking. A task that starts by reading a page, then its frames, then their text and styles, spends read calls before it changes anything.
  • A task that mostly writes uses little of the allowance. A task that mostly reads uses it quickly.
  • If you hit the cap, ask the agent for fewer, narrower reads. Point it at one frame instead of a whole file. Our Figma MCP limit reached page lists the other options.

How FigmaMCP differs

FigmaMCP is a Mac app with a local server and a plugin inside the Figma desktop app. Your agent talks to the local server, and the plugin reads and edits the open file through Figma’s Plugin API on your machine. It does not call Figma’s MCP server, so Figma’s MCP rate limits are not part of how it works, and FigmaMCP has no call quota of its own.

That does not remove every Figma rule. Whether your account can run a development plugin in your file is Figma’s decision, and we have not tested every plan. Try it on one file before you plan around it. See also Official Figma MCP vs FigmaMCP and pricing.

To set it up and make a first read, follow Edit a Figma file with Claude Code in 5 minutes.

What you should know first

  • macOS only for now.
  • It needs the Figma desktop app. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin for you.
  • If you do not allow Accessibility, open the plugin once in each file (Plugins, Development, FigmaMCP) and leave it open while your agent edits.
  • Features that belong to Figma itself, such as Dev Mode, are not included.

Questions

What is the Figma MCP rate limit?
It depends on the seat and plan. As of 2026-11-22, Figma lists up to 20 calls per month for a View or Collab seat on any plan, and for Full or Dev seats up to 200 per day and 10 per minute on Professional, 200 per day and 15 per minute on Organization, and 600 per day and 20 per minute on Enterprise.
Do Figma MCP write calls count against the limit?
No. Figma says the limits apply to tools that read data from Figma, and that some tools are exempt, including tools that write to Figma files. Source: Figma’s rate limits and access page, checked 2026-11-22.
Which calls hit the limit?
Read tools, for example get_design_context, get_metadata and get_screenshot. An agent that looks at a design before it edits it uses these first.
Does FigmaMCP have a call limit?
FigmaMCP has no call quota of its own and does not call Figma’s MCP server. It works through a plugin in your Figma desktop app, so you need your existing access to the file, and edit access to edit.
