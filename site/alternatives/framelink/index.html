Framelink alternative

Framelink reads a Figma file so a coding agent can write code from it. It does not change the file. If your agent must change the design too, FigmaMCP can: it is a free Mac app that lets Claude Code or Codex read and edit the file open in Figma desktop, with no API token. It runs on macOS only.

Framelink, the GLips/Figma-Context-MCP project, is a design-to-code context tool. Facts about it on this page are from its README, checked 2026-11-19. They paraphrase the README and may change.

What Framelink does, and where it stops

Framelink gives AI coding tools access to Figma design data. Its README says to add the server to your client’s MCP config, supply a Figma personal access token that you create in your Figma account settings, then paste a link to a file, frame or group into chat and ask the agent to work with it. The server fetches metadata from the Figma API and trims it to the layout and styling most useful to the model. The README says it is built for Cursor and works with other MCP-capable coding tools.

The README describes fetching design data only. It does not describe changing a Figma file. So people look for an alternative when they need the agent to create frames, edit text or adjust styles, when they do not want to manage a token, or when they want to work on the file open on their screen instead of a link.

What FigmaMCP does differently

FigmaMCP is a free Mac app. It reads and edits the file open in Figma desktop through a local plugin, so there is no token and no link to paste. FigmaMCP has tools to create frames, text and shapes, change fills and strokes, set auto layout, manage styles, variables and components, and export a node as an image. Use page_info and node_info to read, then write tools such as node_set_fill or text_set_content.

Edits only happen where the plugin’s “AI can edit this file” switch is on; with it off, the file is read-only. Each edit names its target layer and the name must match. FigmaMCP validates batches before they run and returns structured errors. FigmaMCP has no call quota of its own.

When Framelink is still the better pick

Framelink is the better pick if you want a coding agent to turn a design into code and you do not need to change the Figma file. Its link-based flow does not need the Figma desktop app on your screen, and its README says other MCP clients can use it. Its output is trimmed for the model, which its README says helps accuracy.

When FigmaMCP fits

FigmaMCP fits if you want the agent to change the design: build screens, fix spacing, rename layers, update text or manage variables. It suits people on a Mac with Claude Code or Codex who prefer a per-file switch to a token. FigmaMCP needs the Figma desktop app and is not on Figma Community. The two tools answer different questions, so some people use Framelink for handoff to code and FigmaMCP for design work. See write tools and Claude Code setup.

Questions

Is there a Framelink alternative that edits Figma files?
FigmaMCP edits the file open in Figma desktop from Claude Code or Codex, on a Mac. Framelink’s README describes fetching only. Source: the Figma-Context-MCP README, checked 2026-11-19.
Does Framelink need a Figma token?
Yes. Its README says you create a Figma personal access token. FigmaMCP needs no API token.
Can I use Framelink and FigmaMCP together?
They are separate tools. Framelink reads a design for coding, and FigmaMCP edits the open file. Avoid having two tools edit the same file at once.
Is FigmaMCP affiliated with Figma?
No. FigmaMCP is independent and is not endorsed by Figma, Inc.
