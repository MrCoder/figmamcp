Is FigmaMCP's source code public?

No. The code that builds FigmaMCP is kept in a private repository. What is public is the built Mac app itself: every release, with a checksum you can verify, in a separate public repository that anyone can browse or file an issue against.

Why keep the code private but the app free

Those are two separate decisions. Keeping the app free and local avoids Figma’s hosted call limits, which is the whole point of how FigmaMCP talks to the Plugin API instead of a hosted server. Keeping the code private is a separate choice about how the project is maintained; it does not change what the app does, what it costs, or what data it sends, which the privacy page lists in full.

How this compares with the upstream project

FigmaMCP started from figma-edit-mcp, which is public. FigmaMCP has since added its own installer, update checks, anonymous usage counts and a plugin connection flow; see the changelog for what has shipped. The two projects are not kept in sync, and this site covers FigmaMCP, not the upstream project.

What you should know first

  • FigmaMCP is not affiliated with or endorsed by Figma, Inc.
  • No Figma API token is used or needed; it works through the Plugin API inside the desktop app.
  • Each release is checksummed; see verifying your download.
  • If you need code you can audit yourself, the upstream project linked above is public, though its feature set differs from FigmaMCP’s.

Questions

Is FigmaMCP's source code public?
No. The code that builds FigmaMCP is kept in a private repository. The built Mac app and its releases are published publicly, with a checksum for each download, in a separate public repository.
Can I read the code myself?
Not FigmaMCP's own code. You can read the project it forks from, figma-edit-mcp by Neo Product LLC, which is public on GitHub.
Where do releases come from, if the code is private?
Each release is built from the private code and published to a public releases repository as a signed, notarized macOS app with a SHA-256 checksum, so you can verify what you downloaded without needing the code.
Is FigmaMCP affiliated with Figma, Inc.?
No. FigmaMCP is not affiliated with or endorsed by Figma, Inc. Figma is a trademark of Figma, Inc.
