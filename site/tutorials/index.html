Figma MCP tutorials

These tutorials show, step by step, how to let Claude Code or Codex work on a live Figma file through FigmaMCP, a free Mac app with a local MCP server and a plugin for the Figma desktop app. Each one is a single task with numbered steps, the prompt to type and what the agent does in reply.

Which one to start with

  1. Start with the 5-minute tutorial if FigmaMCP is new to you. It sets up the app and checks the connection with a read before the first edit.
  2. Then pick the task you have today. To check and fix a frame, run a design QA pass. To start a new screen from a product spec, turn the spec into frames. To clean up a frame before a handoff, rename its layers.
  3. Work on a duplicate of the file or frame the first time, and use Figma version history to undo a change you do not want.

Before you start

Every tutorial needs the same setup: a Mac with macOS 14 or later, the Figma desktop app and Claude Code or Codex. FigmaMCP does not run in the browser, and you do not create a Figma access token. The full reference is Figma MCP setup for Mac.

The three task tutorials each use a skill: a short instruction file that tells the agent which FigmaMCP tools to call and in which order. The FigmaMCP app installs only the base figmamcp skill. You copy the task skill from the FigmaMCP releases page into ~/.claude/skills/ for Claude Code, or ~/.codex/skills/ for Codex, and start a new session.

What stays the same in every tutorial

  • The agent edits only the file where the plugin is open and its AI can edit this file switch is on. With the switch off, it can only read.
  • Each edit must name its target layer exactly, and a bulk edit with one invalid item changes nothing. See Is it safe?
  • The agent tells you what it will change and reports what it did. You still check the result in Figma.

Questions

Do the tutorials work with Codex?
Yes. The steps are the same for Claude Code and Codex. Only the folder you copy a skill into is different.
Do I need a skill for the first tutorial?
No. The first tutorial uses only the base figmamcp skill, which the Mac app installs for you.
Where is the full list of tools?
On the tools page. For jobs described by goal rather than by step, see use cases.
