Figma MCP troubleshooting

Find what you see in the table below, then follow the fix. Most problems have one of three causes: the agent was started before setup, the plugin is not open in the file, or the file is set to read-only. If your agent returned an error code, the table lists it too.

Symptom to fix

FigmaMCP returns structured errors. Each one comes from a fixed rule, so a retry with the same input gives the same result. Change the condition first.

Where to start

Two pages go deeper: Figma MCP not working for connection errors and refused edits, and Plugin not showing in Figma for a missing plugin. FigmaMCP runs only on macOS, needs the Figma desktop app and is not on Figma Community.

Questions

Why does a retry give the same error?
FigmaMCP errors come from fixed rules inside the plugin. Change the condition first, for example open the plugin, turn on the edit switch or refresh the layer name with node_info.
Do I need to reinstall when something fails?
Usually not. Check that your agent was restarted after setup, that the plugin is open in the file, and that AI can edit this file is on.
What does partialMutation mean?
An error with details.partialMutation set to true means a change may have survived a failed step. Do not retry yet. Read whatChanged and before, check the IDs with node_info, and fix the state first.
