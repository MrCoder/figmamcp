Edit Figma with AI, in the file you already have open

To edit a Figma file with AI, connect an agent to the file and describe the change. FigmaMCP connects Claude Code or Codex to the Figma desktop app on your Mac, and the edits appear in your open file.

Jobs that suit an agent

Edits to ask an agent for
JobExample requestCheck afterwards
Clean up layer names“Rename every Frame 12 to match its heading.”Names that depended on unclear headings
Change copy“Replace the old product name in this frame.”Text that overflows its box
Build a layout“Build a pricing card with three tiers using our variables.”Spacing, hierarchy and visual quality
Connect tokens“Bind these colors to our variables.”Layers that had no close match
Add notes“Annotate this screen for developers.”Accuracy of each note

Tool guides for these jobs: auto layout for a layout, components and variants for parts you reuse, and prototype reactions and annotations for notes and prototype interactions.

How to start

  1. Install FigmaMCP

    Open the Mac app and follow its checklist.

  2. Open your file

    Use the Figma desktop app. If you did not allow Accessibility, open the plugin yourself.

  3. Describe the change

    Ask Claude Code or Codex. Name the page or frame, and say what must stay the same.

Download for Mac Version 0.1.25 macOS 14+ · Intel & Apple Silicon · ~155 MB

Keep control

  • Turn off AI can edit this file when you want the agent to read only.
  • Start with one frame before you ask for a whole page.
  • Use Figma version history to go back. A wrong edit that follows the rules still goes through.

See every kind of edit, or fix a connection problem.

What you should know first

  • macOS only for now.
  • It needs the Figma desktop app. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin for you.
  • If you do not allow Accessibility, open the plugin once in each file (Plugins, Development, FigmaMCP) and leave it open while your agent edits.
  • Features that belong to Figma itself, such as Dev Mode, are not included.

Questions

Does AI replace a designer here?
No. The agent makes the changes you describe. You still judge the result.
Can AI edit a file in the browser version of Figma?
Not with FigmaMCP. It needs the Figma desktop app.
Can I undo what the agent did?
Use Figma version history, and review changes as they appear. Start small so that a wrong change is easy to find.
