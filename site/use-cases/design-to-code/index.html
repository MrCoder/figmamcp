Figma to code MCP: the agent reads, then writes the code

FigmaMCP does not write code. It lets Claude Code or Codex read the design in your open Figma file: the layers, the variables and a picture of the frame. Then the agent writes the code in your project with its own tools.

What FigmaMCP gives the agent

FigmaMCP gives your agent two ways to read a design: the layer data and a picture. The agent needs both.

From frame to code, step by step

  1. Open the file

    Open it in the Figma desktop app. You can paste a link to a layer. The server accepts the layer ID from a Figma URL as it is.

  2. Name the target

    Ask for one frame, not the whole file. Say which framework you use and where the code should go.

  3. The agent reads

    It reads the layer tree, the tokens and a picture of the frame.

  4. The agent writes

    It writes the code in your repo with its own file tools.

  5. You compare

    Run the code and compare it with the design. Ask the agent to export the frame again if it needs a second look.

Why read the tokens, not just the picture

A picture shows a blue button. The layer data can show which variable that blue is bound to. Code can then use the variable name instead of a copied hex value. Ask the agent to read the bindings first, and to say when a layer has none. Local variables come from variable_list. Variables from a shared library are read from the layer that uses them.

Example requests

Example design to code requests
You ask What the agent does
“Build this card as a React component.”Reads the card, then writes the component file. Your agent picks the structure.
“Use our variables for color and spacing.”Reads the bound variables on each layer and uses their names in the code.
“List all text in this screen.”Reads the text layers, so the copy can go into a file or a translation table.
“Show me the frame, then write the CSS.”Exports a picture first, then writes styles from what it read.

What to check

Review the code like a colleague’s work. FigmaMCP does not run or test it. It also does not use Figma’s Dev Mode. To link code components to Dev Mode, Figma has Code Connect; see Code Connect vs FigmaMCP. For the reverse direction, see code to design. To read variables on their own, see Figma MCP variables. For setup, see Figma MCP setup, and for Claude Code see Figma MCP for Claude Code.

What you should know first

  • macOS only for now.
  • It needs the Figma desktop app. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin for you.
  • If you do not allow Accessibility, open the plugin once in each file (Plugins, Development, FigmaMCP) and leave it open while your agent edits.
  • Features that belong to Figma itself, such as Dev Mode, are not included.

Questions

Does FigmaMCP generate code?
No. It reads the design. Your agent, Claude Code or Codex, writes the code with its own file tools. You choose the language and framework in your request.
Can I paste a Figma link for a frame?
Yes. The layer ID in a Figma URL is accepted as it is. The file still has to be open in the Figma desktop app.
Does it use Figma Dev Mode?
No. Features that belong to Figma itself, such as Dev Mode, are not included.
Can the agent read my design tokens?
Yes. It reads local variables with variable_list and the variables a layer uses with node_info.
