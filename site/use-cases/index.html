Figma MCP use cases

Pick the job you want done, and the table sends you to the page for it: bulk edits, a read-only audit, building a design from code, or reading a design to write code. Each page uses FigmaMCP, which connects Claude Code or Codex to the Figma file you have open on your Mac. New to it? Start with a job that only reads.

Reading is safer than writing

FigmaMCP splits its tools into reads and writes. The read tools never change the file. They are page_info, node_info, style_list, variable_list, component_list, annotation_list, reaction_list and instance_get_overrides. The audit and design-to-code pages use mostly these. If you are new to the tool, start with one of them.

What every write has in common

FigmaMCP checks each write before it runs. The edit goes only to the open file where the plugin’s AI can edit this file switch is on. Each edit names its target layer, and the name must match the layer’s real name. Batch tools check every item first, so one invalid item stops the call with no change. A refused call returns a structured error, such as NAME_MISMATCH or READ_ONLY_MODE, and the agent can correct the request. A wrong edit that follows the rules still goes through, so keep Figma version history on.

Limits that apply to every page

  • macOS only for now, and the Figma desktop app is required. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin for you.
  • Features that belong to Figma itself, such as Dev Mode, are not included.
  • FigmaMCP is independent. It is not affiliated with Figma, Inc.

Questions

Which use case should I try first?
Try the audit. It only reads, so it cannot change your file. Then try a small bulk edit on a duplicate page.
Do these pages need different setup?
No. Setup is the same for every job: install the Mac app, open your file in the Figma desktop app and ask your agent.
Can FigmaMCP turn a design into code by itself?
No. FigmaMCP lets your agent read the design. The agent writes the code in your project with its own file tools.
Can it import an HTML file into Figma?
No. There is no HTML importer. The agent reads your code and builds frames, text and shapes with the create tools.
