Figma MCP code to canvas: from code to a design file

Your agent reads your code, then builds the matching frames, text and shapes in the Figma file you have open. FigmaMCP has no HTML importer, so the agent does the translating and the create tools do the writing. Expect a draft to review, not a pixel-perfect copy.

FigmaMCP does not import HTML

There is no tool that takes an HTML file or a component and turns it into a Figma layer. To get from HTML to a design, the agent reads your code, decides the layout, and builds frames, text and shapes in your file with the create tools.

Step by step

  1. Describe or point at the code

    Paste the markup, or tell the agent which file to read. The agent reads it from your project.

  2. Pick a parent

    Ask for the page or frame where the result should go. The agent reads that parent first and passes its name back.

  3. Build one frame

    Start with one screen or one component. Do not ask for a whole app at once.

  4. Check the picture

    The agent exports the new frame as an image and looks at it. You look too.

Why the order matters

The create tools need a parent. The agent must read the parent first, then pass its exact name back. A frame needs auto layout before spacing can be bound to a variable, and a fill must be solid or empty before a color variable can be bound. A good request names the page, the frame and the tokens to use. The agent can then follow that order without guessing.

Example requests

Example code to design requests
You ask What the agent does
“Build the login form from login.tsx as a frame.”Reads the file, then creates frames and text with auto layout. It does not import the file.
“Turn this SVG into a layer on the Icons page.”Creates a layer from the markup in the parent you named.
“Use our variables for the colors.”Binds fills to variables, after it sets a solid fill or clears the old one.
“Make this card a component.”Converts the frame to a main component, then you can place instances.

Limits of this direction

  • The agent translates by judgment. It will not match your code pixel for pixel. Review the layout, spacing and hierarchy.
  • It cannot create layers inside a component instance. It edits the main component or uses overrides.
  • Edits go only to the open file where AI can edit this file is on.
  • Figma has its own write-to-canvas feature. For how it differs, see FigmaMCP and the official Figma MCP.

For the other direction, see Figma to code with MCP. For every kind of edit, see what the agent can write.

What you should know first

  • macOS only for now.
  • It needs the Figma desktop app. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin for you.
  • If you do not allow Accessibility, open the plugin once in each file (Plugins, Development, FigmaMCP) and leave it open while your agent edits.
  • Features that belong to Figma itself, such as Dev Mode, are not included.

Questions

Can FigmaMCP import HTML into Figma?
No. There is no HTML importer. The agent reads your code and builds frames, text and shapes with the create tools. The result is the agent’s reading of your code, so review it.
Can the agent turn an SVG into a Figma layer?
Yes. create_svg makes a layer from SVG markup, inside a parent you name.
Will the design match my code exactly?
Not by guarantee. The agent chooses the layout from what it reads. Check the result against your code.
Does it write to the file in my browser?
No. FigmaMCP needs the Figma desktop app on a Mac. It does not run in the browser.
