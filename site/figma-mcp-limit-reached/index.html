Figma MCP limit reached: what it means and what you can do

You see this when your account has used up the number of calls Figma allows its MCP server to answer for your seat. The allowance resets on a schedule that depends on your seat, and it applies to the read tools your agent uses to look at your design. As of November 22, 2026, a View or Collab seat gets 20 read calls per month on every plan. Tools that write to Figma files are exempt.

The published limits

Figma MCP server call limits by seat and plan
Seat and planLimit
View or Collab seat, any plan20 calls per month
Starter plan, Full or Dev seatNot available; Starter has no Full or Dev seat
Pro, Full or Dev seat200 per day, 10 per minute
Organization200 per day, 15 per minute
Enterprise600 per day, 20 per minute

Source: Figma developer docs, MCP server rate limits and access, checked November 22, 2026. Limits may change. Figma’s page is the authority. For what the limit covers, see Figma MCP rate limit by plan.

Why agents hit it quickly

An agent that explores a design before editing it can make many read calls for one task: one for the page, others for frames, text and styles. At 10 calls a minute, a single exploratory prompt can use the minute’s allowance. At 20 a month, a View seat covers very little.

Your options

  1. Wait for the reset. Free, and fine for occasional use.
  2. Use a seat with a higher allowance. That is a Figma plan decision. Compare the table above with what you pay.
  3. Ask for fewer, narrower reads. Point the agent at one frame instead of a whole file.
  4. Use a local option. FigmaMCP reads and edits through the Plugin API of the Figma desktop app on your Mac. It never calls Figma’s MCP server, so these call limits are not part of how it works.

How to set up the local option

If you pick the local option, these four steps take you from the download to a first read. None of them uses your Figma MCP allowance, because FigmaMCP does not call Figma’s MCP server.

  1. Download the app and open it. Download FigmaMCP for Mac, open FigmaMCP.dmg and drag the app to Applications. Then open the app.

  2. Click Add to Figma. The app’s checklist checks for Figma, Claude Code and Codex. Click Add to Figma. Figma restarts once, and only if it was running and the plugin was missing.

  3. Restart your agent. If Claude Code or Codex is running, quit it and start it again, so it loads the new tools.

  4. Open the plugin in your file. Open the file in the Figma desktop app, then choose Plugins › Development › FigmaMCP. The panel shows the connected file. Its AI can edit this file switch must be on before your agent can edit.

Then ask your agent for a read first. Paste this: “List the text layers in the selected frame, with their font and size.” A read cannot change the file, so it is a safe first test.

What you should know first

  • macOS only for now.
  • It needs the Figma desktop app. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin for you.
  • If you do not allow Accessibility, open the plugin once in each file (Plugins, Development, FigmaMCP) and leave it open while your agent edits.
  • Features that belong to Figma itself, such as Dev Mode, are not included.

Questions

Do the limits apply to writing as well as reading?
Figma’s rate-limit page says the limits apply to tools that read data from Figma, and that tools which write to Figma files are exempt. Writing to the canvas is covered separately: it requires a Professional plan or above with edit access, and Figma says it is free in beta and planned to become usage-based. Source and dates are below.
Will upgrading my seat remove the limit?
No. Higher seats get higher limits, not none. Pro Full and Dev seats get 200 calls per day and 10 per minute; Enterprise gets 600 per day and 20 per minute.
Does FigmaMCP count against Figma’s limit?
No. It does not call Figma’s MCP server. It works through the Plugin API inside the desktop app you already have open.
Can these numbers change?
Yes. They are Figma’s numbers as published on November 22, 2026. Check the source page before you rely on them.
