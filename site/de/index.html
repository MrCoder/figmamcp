Dein Agent bearbeitet die Figma-Datei, die du schon geöffnet hast.

Sprache: English · 简体中文 · 繁體中文 · 日本語 · Polski · Français · Deutsch · 한국어 · Українська

FigmaMCP ist ein kostenloses, lokales Tool, mit dem Claude Code oder Codex eine geöffnete Datei in der Figma-Desktop-App lesen und bearbeiten können. Es läuft auf deinem Mac über Figmas Plugin-API, sodass du kein Abruflimit im Blick haben musst.

Für Mac herunterladen Version 0.1.25 macOS 14 oder neuer · Intel & Apple Silicon · ca. 155 MB

So sieht es aus

Was es kann

Sag deinem Agenten in normaler Sprache, was du willst. Er liest die Struktur deiner geöffneten Datei und nimmt die Änderungen direkt in dieser Datei vor, wo du sie live mitverfolgen kannst.

Lesen

Seiten, Frames, Ebenen, Text, Komponenten, Variablen und Styles aus der Datei, die vor dir liegt.

Bearbeiten

Erstelle und ändere Frames, Text, Formen, Komponenten und Instanzen, Auto Layout, Füllungen, Konturen und Effekte.

In großem Maßstab anwenden

Benenne, gestalte oder schreibe viele Ebenen in einer Anfrage um, zum Beispiel jede Textebene mit einem alten Produktnamen.

Innerhalb sicherer Grenzen

Jede Änderung muss ihr Ziel genau benennen, eine Sammeländerung mit einem ungültigen Element ändert gar nichts, und ein Schalter im Plugin kann die Datei schreibgeschützt machen.

So funktioniert es

  1. App herunterladen und öffnen

    Lade FigmaMCP für Mac herunter und öffne es. Es liegt in deiner Menüleiste.

  2. Auf Add to Figma klicken

    Figma startet nur einmal neu, und nur wenn es lief und das Plugin fehlte. Du kannst auch die Bedienungshilfen-Berechtigung erlauben, damit FigmaMCP das Plugin für deine KI öffnen kann.

  3. Deinen Agenten fragen

    Bitte Claude Code oder Codex, deine geöffnete Datei zu ändern. Nichts zu importieren, kein Code zum Einfügen, kein Port zur Auswahl.

Was du zuerst wissen solltest

  • Bisher nur für macOS.
  • Benötigt die Figma-Desktop-App. Läuft nicht im Browser.
  • FigmaMCP ist nicht in der Figma Community. Die Mac-App installiert das Plugin für dich.
  • Wenn du die Bedienungshilfen nicht erlaubst, öffne das Plugin einmal in jeder Datei (Plugins, Development, FigmaMCP) und lass es offen, während dein Agent bearbeitet.
  • Funktionen, die zu Figma selbst gehören, wie der Dev Mode, sind nicht enthalten.

Häufige Fragen

Ist FigmaMCP wirklich kostenlos?
Ja. Es ist kostenlos und hat keine Bezahlstufe. Es ruft Figmas gehosteten MCP-Server nicht auf, daher gelten Figmas Abruflimits pro Sitz nicht dafür. Für die Datei, die du öffnest, gelten weiterhin dein eigener Figma-Plan und Figmas Bedingungen.
Wie unterscheidet es sich von Figmas offiziellem MCP-Server?
Figmas offizieller Server stammt von Figma selbst und funktioniert mit vielen MCP-Clients. In kleineren Plänen sind seine Lese-Aufrufe begrenzt, und sein Schreibzugriff auf die Canvas ist in der Beta und braucht außerhalb von Entwürfen einen Full-Platz. FigmaMCP läuft auf deinem Mac über ein Plugin in der Datei, die du geöffnet hast, ohne API-Token und ohne Aufrufkontingent. Es funktioniert mit Claude Code und Codex, nur unter macOS. Siehe den vollständigen Vergleich.
Wenn zwei Personen dieselbe Datei geöffnet haben, in wessen Figma bearbeitet der Agent?
In der Figma-Desktop-App auf dem Mac, auf dem der Agent läuft. Der Agent spricht mit dem Plugin in dieser App und bearbeitet daher als diese Person, die Bearbeitungsrechte für die Datei braucht. Alle anderen sehen die Änderungen live, wie jede andere Bearbeitung. Ändern zwei Personen im selben Moment dieselbe Ebene, entscheidet Figmas eigene Multiplayer-Synchronisierung: Änderungen an verschiedenen Eigenschaften bleiben beide erhalten, bei derselben Eigenschaft gewinnt die letzte Änderung. FigmaMCP fügt keinen eigenen Merge-Schritt hinzu.
Funktioniert es unter Windows oder Linux?
Noch nicht. FigmaMCP unterstützt bisher nur macOS.
Brauche ich ein Figma-API-Token?
Nein. FigmaMCP kommuniziert über die Plugin-API mit der Figma-Desktop-App auf deinem Mac, also gibt es kein Zugriffstoken zu erstellen oder einzufügen.
Warum ist das Plugin nicht in der Figma Community?
FigmaMCP wird außerhalb der Figma Community verteilt. Du installierst es nicht von Hand: Die Mac-App registriert es für dich in Figma, und es erscheint dann unter Plugins, Development.
Mit welchen Agenten funktioniert es?
Claude Code und Codex sind die getesteten Ziele, und die Mac-App verbindet sie für dich.
Kann der Agent meine Datei zerstören?
Änderungen gehen nur an die Datei, in der das Plugin geöffnet ist und der Schalter AI can edit this file aktiviert ist; schalte ihn aus, und die KI kann nur lesen. Jede Änderung muss ihre Zielebene genau benennen. Sammeländerungen werden geprüft, bevor überhaupt etwas geändert wird. Es bleibt ein Editor: Prüfe das Ergebnis so, wie du die Arbeit eines Kollegen prüfen würdest, und nutze Figmas Versionsverlauf.
Sendet es Anfragen an Figmas Server?
Nein. FigmaMCP ruft weder Figmas Server noch dessen REST API auf. Dein Agent spricht mit einem lokalen MCP-Server, der über localhost mit dem Plugin in der Figma-Desktop-App spricht, und das Plugin liest und bearbeitet die Datei über die Plugin-API innerhalb der App. Deine Änderungen erreichen Figmas Cloud danach genauso wie deine eigenen Änderungen, über die normale Synchronisierung der App. Die einzigen Anfragen, die das Plugin selbst stellt, enthalten keinen Dateiinhalt: eine Startzählung pro Pluginstart mit Pluginversion und einer zufälligen Installations-ID an figmamcp.dev und Google Analytics, sowie gesammelte Aufrufzahlen pro Tool-Name, ohne Inhalt, an figmamcp.dev.
Verlässt mein Design meinen Rechner?
FigmaMCP selbst sendet keinen Dateiinhalt irgendwohin. Dein Agent liest jedoch, was FigmaMCP zurückgibt, und sendet es gemäß den Bedingungen seines eigenen Modellanbieters. Siehe die Datenschutzseite.
Ist das von Figma gemacht?
Nein. Nicht mit Figma, Inc. verbunden oder von ihr unterstützt. FigmaMCP ist ein Fork von figma-edit-mcp von Neo Product LLC.
