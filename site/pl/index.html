Twój agent edytuje plik Figma, który już masz otwarty.

Język: English · 简体中文 · 繁體中文 · 日本語 · Polski · Français · Deutsch · 한국어 · Українська

FigmaMCP to bezpłatne, lokalne narzędzie, które pozwala Claude Code lub Codex odczytywać i edytować plik otwarty w aplikacji desktopowej Figma. Działa na Twoim Macu przez Plugin API Figmy, więc nie trzeba pilnować limitu wywołań.

Pobierz na Maca Version 0.1.25 macOS 14 lub nowszy · Intel i Apple Silicon · ok. 155 MB

Zobacz, jak to działa

Co robi

Powiedz agentowi, czego chcesz, zwykłym językiem. Agent odczytuje strukturę otwartego pliku, a potem wprowadza zmiany w tym samym pliku, więc widzisz je na żywo.

Odczyt

Strony, ramki, warstwy, tekst, komponenty, zmienne i style z pliku, który masz przed sobą.

Edycja

Twórz i zmieniaj ramki, tekst, kształty, komponenty i instancje, auto layout, wypełnienia, obrysy i efekty.

Zmiany na wielu warstwach

Zmieniaj nazwy, style albo treść wielu warstw w jednym żądaniu, na przykład każdej warstwy tekstowej ze starą nazwą produktu.

Bezpieczne granice

Każda edycja musi precyzyjnie wskazywać cel, edycja zbiorcza z jednym nieprawidłowym elementem nie zmienia niczego, a jeden przełącznik w pluginie może ustawić plik tylko do odczytu.

Jak to działa

  1. Pobierz i otwórz aplikację

    Pobierz FigmaMCP na Maca i otwórz. Działa z paska menu.

  2. Kliknij Add to Figma

    Figma uruchomi się ponownie tylko raz, i tylko jeśli była włączona, a pluginu jeszcze nie było. Możesz też zezwolić na Ułatwienia dostępu (Accessibility), żeby FigmaMCP mógł otwierać plugin za Twoją AI.

  3. Poproś agenta

    Poproś Claude Code lub Codex o zmianę otwartego pliku. Nic nie trzeba importować, żadnego kodu do wklejenia i żadnego portu do wybrania.

Co warto wiedzieć na początek

  • Na razie tylko macOS.
  • Potrzebna jest aplikacja desktopowa Figma. Nie działa w przeglądarce.
  • FigmaMCP nie jest dostępny w Figma Community. Aplikacja na Maca instaluje plugin za Ciebie.
  • Jeśli nie zezwolisz na Ułatwienia dostępu, otwórz plugin ręcznie w każdym pliku (Plugins, Development, FigmaMCP) i zostaw go otwartym, gdy agent edytuje.
  • Funkcje należące do samej Figmy, takie jak Dev Mode, nie są objęte.

Najczęstsze pytania

Czy FigmaMCP jest naprawdę bezpłatny?
Tak. Jest bezpłatny i nie ma płatnego planu. Nie wywołuje hostowanego serwera MCP Figmy, więc limity wywołań na stanowisko w Figmie go nie dotyczą. Do otwieranego pliku wciąż stosuje się Twój własny plan Figmy i warunki Figmy.
Czym różni się od oficjalnego serwera MCP Figmy?
Oficjalny serwer Figmy jest dostarczany przez Figmę i działa z wieloma klientami MCP. W mniejszych planach jego wywołania odczytu są limitowane, a zapis na canvasie jest w becie i poza szkicami wymaga miejsca Full. FigmaMCP działa na Twoim Macu przez plugin w otwartym pliku, bez tokenu API i bez przydziału wywołań. Działa z Claude Code i Codex, tylko na macOS. Zobacz pełne porównanie.
Jeśli dwie osoby mają otwarty ten sam plik, czyją Figmę edytuje agent?
Aplikację desktopową Figma na tym Macu, na którym działa agent. Agent komunikuje się z pluginem w tej aplikacji, więc edytuje jako ta osoba, która musi mieć dostęp do edycji pliku. Pozostali widzą zmiany na żywo, jak każdą inną edycję. Jeśli dwie osoby zmienią tę samą warstwę w tej samej chwili, rozstrzyga to własna synchronizacja wieloosobowa Figmy: zmiany różnych właściwości zostają obie, a przy tej samej właściwości wygrywa ostatnia zmiana. FigmaMCP nie dodaje własnego kroku scalania.
Działa na Windows albo Linux?
Jeszcze nie. FigmaMCP obsługuje na razie tylko macOS.
Czy potrzebuję tokenu API Figmy?
Nie. FigmaMCP komunikuje się z aplikacją desktopową Figma na Twoim Macu przez Plugin API, więc nie ma tokenu dostępu do tworzenia czy wklejania.
Czemu plugin nie jest w Figma Community?
FigmaMCP jest rozpowszechniany poza Figma Community. Nie instalujesz go ręcznie: aplikacja na Maca rejestruje go w Figmie za Ciebie, a potem pojawia się w Plugins, Development.
Z jakimi agentami działa?
Claude Code i Codex to przetestowane cele, a aplikacja na Maca łączy je za Ciebie.
Czy agent może zniszczyć mój plik?
Zmiany trafiają tylko do pliku, w którym plugin jest otwarty i przełącznik AI can edit this file jest włączony; po jego wyłączeniu AI może tylko odczytywać. Każda edycja musi precyzyjnie wskazywać warstwę docelową. Edycje zbiorcze są sprawdzane przed wprowadzeniem jakiejkolwiek zmiany. To wciąż edytor: sprawdzaj wynik tak, jak sprawdzałbyś pracę kolegi, i korzystaj z historii wersji Figmy.
Czy wysyła żądania do serwerów Figmy?
Nie. FigmaMCP nie wywołuje serwerów Figmy ani REST API. Twój agent rozmawia z lokalnym serwerem MCP, ten serwer rozmawia z pluginem w aplikacji desktopowej Figma przez localhost, a plugin odczytuje i edytuje plik przez Plugin API wewnątrz aplikacji. Twoje zmiany trafiają do chmury Figmy tak samo jak Twoje własne edycje, przez normalną synchronizację aplikacji. Żądania wysyłane przez sam plugin nie zawierają treści pliku: jedno zliczenie uruchomienia na start pluginu, z wersją pluginu i losowym identyfikatorem instalacji, do figmamcp.dev i Google Analytics, oraz zbiorcze liczby wywołań narzędzi według nazwy narzędzia, bez treści, do figmamcp.dev.
Czy mój projekt opuszcza mój komputer?
Sam FigmaMCP nigdzie nie wysyła treści pliku. Twój agent jednak odczytuje to, co zwraca FigmaMCP, i wysyła to do swojego dostawcy modelu, zgodnie z jego warunkami. Zobacz stronę prywatności.
Czy to zrobiła Figma?
Nie. Nie jest powiązany z Figma, Inc. ani przez nią zatwierdzony. FigmaMCP jest forkiem figma-edit-mcp od Neo Product LLC.
