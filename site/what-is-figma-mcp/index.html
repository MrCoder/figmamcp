What is a Figma MCP server?

A Figma MCP server is a program that gives an AI agent, such as Claude Code, tools for Figma. With one connected, the agent can read your design and, with some servers, change it. MCP stands for Model Context Protocol, an open way for agents to call outside tools.

How it works

  1. You ask your agent

    For example: “Build this page from the selected frame.”

  2. The agent calls a tool

    The MCP server lists tools, and the agent picks one.

  3. The server talks to Figma

    Through a hosted service, the desktop app, the REST API or a plugin. This choice sets what the server can do.

  4. The result returns

    The agent reads the answer and decides the next step.

Try it on your own file

To see these four steps on a real file, try FigmaMCP, a free plugin server for Mac. Setup takes about five minutes.

  1. Download the app and open it. Download FigmaMCP for Mac, open FigmaMCP.dmg and drag the app to Applications. Then open the app.

  2. Click Add to Figma. The app’s checklist checks for Figma, Claude Code and Codex. Click Add to Figma. Figma restarts once, and only if it was running and the plugin was missing.

  3. Restart your agent. If Claude Code or Codex is running, quit it and start it again, so it loads the new tools.

  4. Open the plugin in your file. Open the file in the Figma desktop app, then choose Plugins › Development › FigmaMCP. The panel shows the connected file. Its AI can edit this file switch must be on before your agent can edit.

Then ask your agent for a read first. Paste this: “List the text layers in the selected frame, with their font and size.” A read cannot change the file, so it is a safe first test.

Where FigmaMCP fits

FigmaMCP is a free plugin server for Mac. It works on the file open in your Figma desktop app, needs no API token, and does not use Figma’s MCP call limits. See all its tools, or compare local and remote servers.

What you should know first

  • macOS only for now.
  • It needs the Figma desktop app. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin for you.
  • If you do not allow Accessibility, open the plugin once in each file (Plugins, Development, FigmaMCP) and leave it open while your agent edits.
  • Features that belong to Figma itself, such as Dev Mode, are not included.

Questions

Is a Figma MCP server the same as a Figma plugin?
No. A plugin runs inside Figma. An MCP server gives an agent tools. FigmaMCP uses both: the server serves the agent and the plugin acts inside Figma.
Is Figma MCP free?
It depends on the server. Figma's own server has limits by plan and seat. FigmaMCP is free. See the pricing page for details.
Does the agent send my design to a model?
What the agent reads goes to its own model provider, under that provider's terms. FigmaMCP sends no design content to us.
