Figma MCP components

FigmaMCP lets Claude Code or Codex turn frames into components, combine them into variant sets, add component properties, place instances and copy overrides between instances in the Figma file you have open. You describe the component. The agent picks the tools and passes each layer name back exactly.

Build a button with variants

FigmaMCP builds a variant set in two stages. First create_component converts an existing frame into a main component. It takes the frame’s ID and exact name. Then create_component_set combines components into one set.

  1. Read each frame with node_info. Each one must be unlocked and not inside an instance.
  2. Convert each frame with create_component.
  3. Choose property names, for example Size. Give every component one value per property, such as Small.
  4. Read the parent that will hold the set, then call create_component_set with parentId and parentNodeName.

Every combination of values must be unique. A value cannot be empty, and it cannot contain = or ,. The parent cannot be one of the components you combine. A component that already sits in another set cannot be combined. If the combine fails halfway, the error can carry details.partialMutation: true. Read that evidence before you retry.

Properties and instances

FigmaMCP’s component_manage_property adds or edits a property on a main component or a set. The property type is BOOLEAN, TEXT or INSTANCE_SWAP. ADD needs a type and a default value. EDIT can rename the property or change its default. component_delete_property removes a property, and that change reaches every instance.

create_instance places an instance from a componentId, or from a componentKey for a library component. It needs x, y and a named parent. Pass a variant, not a component set. instance_set_property sets one property on one instance. instance_get_overrides reads the overrides of a source instance. instance_set_overrides applies them to several target instances. It swaps each target to the source component first.

FigmaMCP can place an instance of a library component with componentKey. Read the key from an existing instance’s main component, and make sure the library is enabled for the file. Locked layers are not edited. See Figma MCP design system for styles and variables.

Questions

Can it build a button with variants?
Yes: it can create a component set and add properties. Review the result.
Can it edit a library component?
Assets from shared libraries are not edited. They are read-only in your file. You can still place instances of them and change their overrides.
How do I copy text and property changes from one instance to others?
Ask the agent to read the overrides of the source instance with instance_get_overrides, then apply them to the targets with instance_set_overrides. Each target must be an instance, and its name must match.
Can it change a layer inside an instance?
It can set properties and overrides. It cannot delete, group or add layers inside an instance. For those edits, change the main component.
