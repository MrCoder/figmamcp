Figma MCP design system: build and apply one with your agent

Your agent can build a design system in the Figma file you have open: variables for tokens, then styles, components and variants, then instances on a screen. With FigmaMCP, that agent is Claude Code or Codex. You state the rules, such as names and spacing steps. FigmaMCP makes the edits but does not enforce your rules.

The parts of a design system, and who does what

Design system parts and FigmaMCP tools
Part Tools What the agent can do
Tokensvariable_list, variable_manage, node_bind_variableRead tokens, create them, and bind them to layers.
Stylesstyle_list, style_manage, node_apply_styleRead local styles, create or update paint, text, effect and grid styles, and apply a style to a layer.
Componentscomponent_list, create_component, create_component_setList components, turn a frame into a component, and combine components into variants.
Component propertiescomponent_manage_propertyAdd or edit boolean, text and instance-swap properties.
Instancescreate_instance, instance_set_propertyPlace an instance and set its properties.
Layoutnode_set_auto_layoutSet direction, padding, spacing and alignment on a frame.

Build it in this order

Work in layers, and review each one before the next.

  1. Tokens first

    Ask for collections and variables: color, spacing, radius. Review the scopes the agent picks.

  2. Then styles

    Ask for text and effect styles that match your tokens.

  3. Then components

    Ask for one component, such as a button. Combine variants with a component set only after the first one looks right.

  4. Then instances

    Ask the agent to place instances in a screen and bind spacing to tokens.

How it runs with Claude Code

Claude Code or Codex talks to FigmaMCP, and FigmaMCP acts in the Figma desktop app on your Mac. Your instructions live in your prompt. Name the collection, the naming pattern and the order of work, and the agent will pass those names back to the tools. See Figma MCP for Claude Code for setup.

Your rules, and the rules FigmaMCP enforces

FigmaMCP does not store or enforce your design rules. It will not reject a badly named variable or an off-grid spacing value. State your rules in the request and review the result. What FigmaMCP does enforce is safety:

  • Edits go only to the open file where AI can edit this file is on.
  • Each edit names its target, and the name must match.
  • A batch with one invalid item changes nothing.
  • Layers inside component instances are not edited directly. Edit the main component, or use instance overrides.
  • Library assets are read-only. The agent can read a library variable or style from a layer that uses it, and it can edit an instance of a library component through overrides.

Example requests

Example design system requests
You ask What the agent does
“Create a Colors collection with brand and neutral variables.”Creates the collection and variables. You review names and scopes.
“Turn this button frame into a component.”Converts the frame to a main component, after reading its name and parent.
“Combine these three buttons into a Size variant set.”Builds a component set with a Size property.
“Apply the Heading style to these titles.”Applies the named text style to each layer.

What you should know first

  • macOS only for now.
  • It needs the Figma desktop app. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin for you.
  • If you do not allow Accessibility, open the plugin once in each file (Plugins, Development, FigmaMCP) and leave it open while your agent edits.
  • Features that belong to Figma itself, such as Dev Mode, are not included.

Questions

Can Claude Code create a design system in Figma with FigmaMCP?
It can create variables, styles, components and variants in your open file. The result depends on your prompt, so review each layer of the system before you build on it.
Does FigmaMCP enforce my design system rules?
No. It does not store naming or spacing rules. It enforces safety checks, such as matching names and the AI can edit this file switch. Put your rules in your request.
Can the agent edit components from a shared library?
Not the library definitions, which are read-only. It can edit an instance of a library component through overrides.
Do I need a Figma API token?
No. FigmaMCP works through the Figma desktop app on your Mac, so there is no token to create.
