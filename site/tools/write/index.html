Figma MCP write: what your agent can create and edit

Your agent can create and change frames, shapes, text, components, instances, styles, variables and auto layout in the Figma file you have open. With FigmaMCP, that agent is Claude Code or Codex, and every write passes safety checks before it runs.

What the agent can do

What the agent can create and edit, by group
GroupWhat it can do
Frames and structureCreate frames. Group, ungroup, clone, rename, move, resize and delete layers. Move a layer into another parent.
Shapes and vectorsCreate rectangles, ellipses, polygons and stars. Create a shape from SVG. Set fills, strokes, effects and corner radius.
TextCreate text layers. Change the words. Change font, size and other text style.
ComponentsCreate components and component sets. Add and manage component properties.
InstancesCreate instances of a component. Set their properties and overrides.
StylesCreate and edit paint, text, effect and grid styles. Apply a style to a layer.
VariablesCreate and edit variables and collections. Bind a variable to a layer property so it follows the token.
Auto layoutTurn on auto layout for a frame. Set direction, spacing, padding and alignment.

The agent can also read: pages, layers, components, styles and variables, plus a picture of a layer. Reads never change the file. Annotations and prototype reactions are included too.

The safety checks, in plain words

  • Only the file you chose. Writes go only to the file where the plugin is open and its AI can edit this file switch is on. Switch it off and the agent can only read.
  • Right layer, by name. To change an existing layer, variable or style, the agent must give its current name. If the name does not match, the edit is refused.
  • Bulk edits are checked first. If one item in a batch is invalid, nothing in the batch changes.
  • Locked layers stay locked. Locked layers, assets from shared libraries, and the inside of component instances are not edited around.
  • Variables and styles follow the same switch. With it off, the agent can only read them.
  • Clear errors. A refused edit returns a plain reason, and the agent can correct the request.

A wrong edit that follows the rules still goes through, because the checks cannot know what you meant. Review the result, and use Figma version history. For setup, see Figma MCP setup.

How this relates to Figma’s own write tools

Figma’s official server has its own way to write to the canvas. Figma says it needs a Professional plan or above with edit access, and that it is free in beta and planned to become usage-based. See Figma’s write to canvas page, checked November 22, 2026. FigmaMCP works differently: through a development plugin in the desktop app. Whether your account can run one is up to Figma, and we have not tested every plan.

What you should know first

  • macOS only for now.
  • It needs the Figma desktop app. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin for you.
  • If you do not allow Accessibility, open the plugin once in each file (Plugins, Development, FigmaMCP) and leave it open while your agent edits.
  • Features that belong to Figma itself, such as Dev Mode, are not included.

Questions

Can the agent create a new design from scratch?
It can build frames, shapes, text and components, and lay them out with auto layout. The result is only as good as your prompt, so review it.
Can it change my variables and styles?
Yes, while the AI can edit this file switch is on. With it off, the agent can only read them.
Can the agent delete my work?
Only layers inside the file where the plugin is open and its AI can edit this file switch is on. Locked layers are protected, and the layer it deletes must be named correctly. Use Figma version history as your safety net.
Does writing use Figma’s MCP limits?
No. FigmaMCP does not call Figma’s MCP server. It works through the Plugin API inside the desktop app. Figma’s own write terms are described above.
