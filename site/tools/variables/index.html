Figma MCP variables: read and edit your design tokens

With FigmaMCP, Claude Code or Codex can read the variables in your open Figma file, create and change them, bind them to layers, and delete them. There is no tokens-file export, but the agent can write one from what it reads. Reading variables is a good first job for an agent, because it changes nothing.

What the agent can do with variables

Variable jobs and the tools behind them
Job Tool What happens
Read every variablevariable_listLists the local variables and collections in the open file.
See what one layer usesnode_info with boundVariablesReturns the variables bound to that layer, so the agent can check a button before it changes it.
Find where a variable is usedvariable_list with includeConsumersScans one page or the whole document for the layers that use it. The scan is optional and off by default.
Create a collection or variablevariable_manageCreates it. A new variable needs its collection name and its scopes.
Change a variablevariable_manageUpdates it. The agent must pass the variable’s current name.
Delete a variable or collectionvariable_deleteChecks the whole file first. If a layer still uses the variable, the delete is refused.
Make a layer follow a tokennode_bind_variableBinds the variable to a layer property, so the layer tracks the token.

Can Figma MCP read variables?

Yes. This is the first job most people give the agent. Ask Claude Code or Codex to list the variables in your file. It calls variable_list and answers from what Figma returns. You can also ask what a single layer is bound to.

One limit matters. variable_list returns local variables only. Variables that come from a shared library do not appear in it. To use one, the agent reads it from a layer that already uses it.

Export variables to a tokens file

FigmaMCP has no export button and no tool that writes a tokens file. It does not export variables to JSON by itself. What works is this: your agent reads the variables with variable_list, then writes the file in your project with its own file tools. You choose the format. Ask for CSS custom properties, a JSON file or a theme object, and check the result against Figma before you commit it.

Ask in plain words

Example requests for variables
You ask What the agent does
“List every color variable in this file.”Reads the collections and variables, then summarizes them.
“Write our spacing variables to tokens.json.”Reads them, then writes the file in your repo. FigmaMCP only supplies the read.
“Add a variable called surface-raised to Colors.”Creates it in the named collection with the scopes it chooses. Review the scopes.
“Delete the old brand-blue variable.”Refused if layers still use it. The reply lists the consumers.
“Bind this card’s fill to surface-raised.”Binds the variable. The fill must be solid or empty first.

Rules that apply

  • The switch. Variable edits need the plugin’s AI can edit this file switch to be on. With it off, the agent can only read variables.
  • Names must match. To change or delete a variable, the agent passes its current name. A wrong name is refused.
  • Scopes are explicit. A new variable needs its scopes set when it is created.
  • Deletes are guarded. A variable that layers still use is not deleted. If a page cannot be read, the delete is refused too.

What you should know first

  • macOS only for now.
  • It needs the Figma desktop app. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin for you.
  • If you do not allow Accessibility, open the plugin once in each file (Plugins, Development, FigmaMCP) and leave it open while your agent edits.
  • Features that belong to Figma itself, such as Dev Mode, are not included.

Questions

Can Figma MCP read variables?
Yes. The agent lists the local variables and collections in your open file with variable_list. It can also read which variables a single layer uses.
Can I export Figma variables to a JSON file?
FigmaMCP has no export tool for that. Your agent reads the variables, then writes the JSON file itself in your project. You choose the format and check the result.
Does it see variables from a team library?
Not through variable_list, which returns local variables only. The agent can read a library variable from a layer that uses it.
Can the agent delete a variable that layers use?
No. The delete is refused while layers still use the variable. The agent must rebind or clear those layers first.
