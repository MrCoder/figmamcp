Figma MCP export image: how the agent sees a layer

Your agent can render any layer in your open Figma file to PNG, JPG, SVG or PDF with one FigmaMCP tool, node_export_visual. That is how Claude Code or Codex sees your design and checks its own edits. The export only reads, at a scale you choose, and never changes the file.

What node_export_visual returns

Export formats
Format What comes back Good for
PNGA base64 image. Clients that support it show the image inline.Checking a layout after an edit, or showing the agent what a design looks like.
JPGA base64 image, same as PNG.A smaller picture of a photo-heavy layer.
SVGRaw SVG markup the agent can read directly.Inspecting the structure of an icon or shape.
PDFA base64 file, a delivery artifact.A PDF of a layer. Prefer PNG or SVG when the agent needs to look.

Download for Mac Version 0.1.25 macOS 14+ · Intel & Apple Silicon · ~155 MB

How the export works

The agent names one layer, a format and a scale. The layer can be a single icon or a whole frame. FigmaMCP renders it in the Figma desktop app.

The tool returns the image data to the agent. Saving that data as a file in your project is a step the agent does with its own file tools. FigmaMCP does not save files itself.

Why the agent exports at all

An agent that only reads layer data cannot see spacing, color or overlap. It reads numbers and names. An exported picture lets it look at the result. A common loop is: the agent changes a frame, exports it, looks, and fixes what it finds. You can also ask for a picture at any time, for example before you approve a change.

Scale

Use a scale of about 1.0 for a few layers. Use 0.3 to 0.5 for a large group, so the reply stays small. To check a big edit, export one chunk at half scale, fix what you see, then export the whole frame at a low scale for a final look.

Example requests

Example export requests
You ask What the agent does
“Show me the pricing frame as it looks now.”Exports the frame as PNG and looks at the image.
“Export this icon as SVG.”Exports the layer as SVG and returns the markup. It can then write it to a file if you ask.
“Check that the new card matches the old one.”Exports both layers and compares the pictures.
“Replace the headline, then show me the result.”Edits the text, then exports the frame at a low scale to verify.

What export does not do

  • It does not export variables or tokens. For that, see Figma MCP variables.
  • It does not write code. For code, see Figma to code with MCP.
  • It works on the file open in the Figma desktop app. It does not work in the browser.

FigmaMCP has no call quota. For Figma’s own limits, see Figma MCP limit reached. For all tools, see the tools list.

What you should know first

  • macOS only for now.
  • It needs the Figma desktop app. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin for you.
  • If you do not allow Accessibility, open the plugin once in each file (Plugins, Development, FigmaMCP) and leave it open while your agent edits.
  • Features that belong to Figma itself, such as Dev Mode, are not included.

Questions

Can Figma MCP export an image of a layer?
Yes. node_export_visual renders a layer to PNG, JPG, SVG or PDF at a scale you choose. It only reads, so your file does not change.
Does the export save a file to my computer?
The tool returns the image data to your agent. If you want a file in your project, the agent writes it with its own file tools.
Can I export a whole frame, not just one icon?
Yes. Ask the agent to export the frame. For large frames use a lower scale so the reply stays small.
Does exporting count against a call quota?
FigmaMCP has no call quota. See Figma MCP limit reached for Figma’s own limits.
