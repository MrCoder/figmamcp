Figma MCP write to canvas

Figma’s official MCP server can write to the canvas. Figma says that needs a Professional plan or above with edit access, and that it is free in beta and planned to become usage-based (checked November 22, 2026). FigmaMCP writes through a plugin in the desktop app instead.

How FigmaMCP writes to the canvas

FigmaMCP writes to the canvas in the Figma file you have open. Your agent, Claude Code or Codex, calls a tool on the local FigmaMCP server. The server passes the call to the FigmaMCP plugin in the Figma desktop app, and the plugin makes the change. FigmaMCP does not call Figma’s MCP server, so Figma’s write terms and limits are not part of how it works.

The order of a safe write

FigmaMCP makes a write in three steps. First, the agent reads. It calls page_info, then node_info, to get real IDs and names. Second, it writes. A creator such as create_frame needs a parentId and the parent’s exact name as parentNodeName. Third, it looks at the result with node_export_visual. If any step fails, the agent reads the error, fixes the input and tries again.

Rules every write follows

  • One file. Writes go only to the file where the plugin is open and AI can edit this file is on. With it off, the agent can only read, and a write fails with READ_ONLY_MODE.
  • Right layer, by name. To change an existing layer, the agent must pass its current name. A mismatch is refused.
  • Batches first. FigmaMCP checks a whole batch before it runs, so one invalid item means no change.
  • Protected layers. Locked layers, shared-library assets and the inside of component instances are not edited around.

A wrong edit that follows these rules still goes through. FigmaMCP cannot know what you meant. Review the result and use Figma version history.

Questions

Is write to canvas free?
Figma says it is free during beta and planned to become usage-based.
Does FigmaMCP use that allowance?
No. It does not call Figma’s MCP server.
Which tool creates a new frame?
create_frame. It needs a parentId and the parent’s exact name as parentNodeName, both read from page_info or node_info.
Why was my write refused?
Common reasons are that AI can edit this file is off (READ_ONLY_MODE), the layer name did not match, or the layer is locked. The error says which.
