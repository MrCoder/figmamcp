Figma MCP integrations

FigmaMCP connects the Figma desktop app on your Mac to your coding agent. Two integrations exist today: Claude Code and Codex. The Mac app adds the Figma plugin and connects both agents, with no API token. Other clients are not supported yet. This page points you to the right guide.

What the Mac app sets up

FigmaMCP’s Mac app runs a checklist. It looks for Figma, Claude Code and Codex. Then it installs the plugin and connects the agents it found. You do not edit config files or copy a token.

What the app sets up
PartWhat happens
Figma pluginAdded to Figma’s development plugins. You find it under Plugins, Development, FigmaMCP. Figma restarts once, and only if it was running and the plugin was missing.
Claude CodeThe app adds a user-scope MCP entry named figmamcp and a FigmaMCP skill, if Claude Code is installed.
CodexThe app adds an MCP entry named figmamcp and the same skill, if Codex is installed.
Local relayA small background process that starts at login. It passes messages between the agent’s server and the plugin.
Accessibility (optional)If you allow it, FigmaMCP can open the plugin for your agent. If you do not, open the plugin once in each file and leave it open.

Restart Claude Code or Codex if it was already running, so it loads the new tool. The setup page lists every file and setting the installer writes, and how to remove them.

What both agents get

Both agents use the same FigmaMCP tools. They can read pages, layers, styles, variables, components, annotations and prototype reactions. They can also create shapes, frames, text and components, and edit layers. Edits go only to the open file where the plugin’s AI can edit this file switch is on. Each edit names its target layer, and the name must match. Turn the switch off and the agent can read but not edit.

If the connection fails

Connection problems
ErrorMeaningWhat to do
PLUGIN_PEER_UNAVAILABLENo Figma plugin is connected to that channel.Open the FigmaMCP plugin in the file, then retry.
CHANNEL_NOT_BOUNDThe session has no channel. This appears when several files have the plugin open.Call channel_join with the plugin’s link for the file you want.
PLUGIN_DISCONNECTEDThe plugin closed, reloaded or was re-scoped while a command ran.Check with node_info whether the edit took effect, then retry once the plugin is open.
READ_ONLY_MODEThe AI can edit this file switch is off.Turn it on in the plugin.

With one file open, a tool connects by itself on its first call. See Figma MCP not working for more.

Limits

  • macOS 14 or later, on Intel or Apple Silicon.
  • The Figma desktop app is required. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin.
  • FigmaMCP is independent. It is not made by Figma, Inc.

Questions

Which agents does FigmaMCP support?
Claude Code and Codex. Other clients are not supported yet.
Do I need a Figma API token?
No. FigmaMCP works through the Figma desktop app on your Mac, so there is no token to create or paste.
Do I configure Claude Code or Codex myself?
No. The Mac app adds the FigmaMCP entry for each agent it finds. If an agent was already running, restart it.
Can I use Claude Code and Codex on the same file?
Both can connect to the same plugin. FigmaMCP lets several agent sessions share one plugin, so watch that two agents do not edit the same layers.
