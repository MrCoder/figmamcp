Figma MCP for Claude Code

Yes. Claude Code can edit a live Figma file if it is connected to a tool that can act inside Figma. FigmaMCP is a free one: Claude Code talks to a small local MCP server, the server talks to a plugin in your Figma desktop app, and the edits appear in your file. It needs macOS, the desktop app, and no API token.

Set up

Four steps connect Claude Code to the file open in Figma. You do not edit a config file, and you do not create a Figma access token. If you also allow Accessibility, which is optional, FigmaMCP can open the plugin for Claude Code.

  1. Download the app and open it. Download FigmaMCP for Mac, open FigmaMCP.dmg and drag the app to Applications. Then open the app.

    Download for Mac Version 0.1.25 macOS 14+ · Intel & Apple Silicon · ~155 MB

  2. Click Add to Figma. The app’s checklist checks for Figma, Claude Code and Codex. Click Add to Figma. Figma restarts once, and only if it was running and the plugin was missing.

  3. Restart Claude Code. If Claude Code is running, quit it and start it again, so it loads the new tools.

  4. Open the plugin in your file. Open the file in the Figma desktop app, then choose Plugins › Development › FigmaMCP. The panel shows the connected file. Its AI can edit this file switch must be on before your agent can edit.

Then ask Claude Code for a read first. Paste this: “List the text layers in the selected frame, with their font and size.” A read cannot change the file, so it is a safe first test.

Prompts that work well

You askWhat happens
“On this page, rename every layer called Frame 12 to match its heading.”Claude Code reads the page, then renames the matching layers in one validated batch.
“Replace the old product name in all text layers in this frame.”It finds the text layers in the frame and rewrites them together.
“Build a pricing card with three tiers using our variables.”It creates frames and text with auto layout, bound to your variables while the AI can edit this file switch is on.
“Delete this color variable.”Refused if layers still use it, so you do not get broken references.

Guardrails you control

  • Edits go only to the open file where the plugin’s AI can edit this file switch is on. Turn the switch off and the agent can read but not edit.
  • Each edit names its target layer, and the name must match.
  • Variables and styles follow the same switch: off means they are read-only too.
  • A wrong edit that follows the rules still goes through. Review the result, and use Figma version history.

What you should know first

  • macOS only for now.
  • It needs the Figma desktop app. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin for you.
  • If you do not allow Accessibility, open the plugin once in each file (Plugins, Development, FigmaMCP) and leave it open while your agent edits.
  • Features that belong to Figma itself, such as Dev Mode, are not included.

Questions

Does Claude Code need a Figma token to edit a file?
Not with FigmaMCP. It works through the Figma desktop app on your Mac, so there is no access token to create.
Does the file need to be open?
Yes. The file must be open in the Figma desktop app. With the Mac app, FigmaMCP can open the plugin for you after you allow Accessibility. Without it, open the plugin yourself once per file.
Can Claude Code edit a file I did not open?
No. It edits the live file in front of you, and only while its AI can edit this file switch is on.
What if an edit is refused?
The tool returns a structured error explaining why, for example the layer name did not match or the file is switched to read-only. Claude Code can then correct the request.
Does this work with Codex?
Yes. Codex is a supported target. Setup connects it for you; see the setup note above.
