Figma MCP pricing: FigmaMCP is free right now

FigmaMCP is free. You pay nothing, you create no account, and you need no Figma API token. We may set a price later, and we do not promise it will stay free forever. Figma’s own Figma MCP server comes with your Figma plan instead, with call limits set by your seat. This page shows both.

How to use FigmaMCP

There is nothing to buy and nothing to sign up for. Four steps take you from the download to a first answer from your file.

  1. Download the app and open it. Download FigmaMCP for Mac, open FigmaMCP.dmg and drag the app to Applications. Then open the app.

  2. Click Add to Figma. The app’s checklist checks for Figma, Claude Code and Codex. Click Add to Figma. Figma restarts once, and only if it was running and the plugin was missing.

  3. Restart your agent. If Claude Code or Codex is running, quit it and start it again, so it loads the new tools.

  4. Open the plugin in your file. Open the file in the Figma desktop app, then choose Plugins › Development › FigmaMCP. The panel shows the connected file. Its AI can edit this file switch must be on before your agent can edit.

Then ask your agent for a read first. Paste this: “List the text layers in the selected frame, with their font and size.” A read cannot change the file, so it is a safe first test.

How this compares with Figma’s official MCP server

Figma’s own MCP server is a hosted service with call limits by seat and plan. FigmaMCP is a different design: a local server on your Mac talks to a plugin in the Figma desktop app. It does not call Figma’s MCP server, so Figma’s read limits are not part of how it works.

Writing is a separate matter

Figma says its write tools are exempt from those read limits. Writing to the canvas with Figma’s server requires a Professional plan or above with edit access. Figma says it is free in beta and planned to become usage-based. See Figma’s write to canvas page, checked November 22, 2026, or our own page on Figma MCP write to canvas for the official terms next to a local option.

So the official server is not only a read-limit story, and we do not claim that it is. The two tools work in different ways. Pick the one that fits how you work. For plan-by-plan detail, see Figma MCP on the free plan, Figma MCP Starter plan limit, and Figma MCP limit reached.

What you should know first

  • macOS only for now.
  • It needs the Figma desktop app. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin for you.
  • If you do not allow Accessibility, open the plugin once in each file (Plugins, Development, FigmaMCP) and leave it open while your agent edits.
  • Features that belong to Figma itself, such as Dev Mode, are not included.

FigmaMCP is independent software. Your use of the Figma desktop app remains subject to Figma’s terms.

Questions

Is FigmaMCP free?
Yes, today. There is no charge, no sign-up and no API token. We may decide on pricing later and we do not promise it will stay free forever.
Is Figma’s official MCP server free?
Figma publishes call limits by seat and plan, and says write to canvas needs a Professional plan or above with edit access, free in beta and planned to become usage-based. Check Figma’s pages, linked above, for the current terms.
What does Figma MCP cost on an Enterprise plan?
Figma’s MCP server comes with your Figma plan. What changes on Enterprise is the read limit: up to 600 calls per day and 20 per minute for a Full or Dev seat, and 20 per month for a View or Collab seat, as Figma listed it on 2026-11-22. Write tools are exempt. See Figma MCP rate limit for every plan. FigmaMCP costs nothing on any plan and has no call quota. We have not tested an Enterprise account; what matters is whether your organization lets you run a development plugin, so try it on one file first.
Do Figma’s read limits apply to FigmaMCP?
No. FigmaMCP does not call Figma’s MCP server. It works through the Plugin API inside the desktop app you already have open.
Will I need to pay Figma to use FigmaMCP?
FigmaMCP runs a development plugin in the Figma desktop app, so what matters is whether your account lets you run one in your file. We have not tested every plan. Try it on one file first.
