Figma MCPサーバーとは？

言語： English · 简体中文 · 日本語

Figma MCPサーバーは、Claude CodeなどのAIエージェントにFigma用のツールを提供するプログラムです。接続すると、エージェントはデザインを読み取れるようになり、サーバーによっては変更もできます。MCPはModel Context Protocolの略で、エージェントが外部のツールを呼び出すためのオープンな仕組みです。

仕組み

  1. エージェントに頼む

    たとえば「選択中のフレームからこのページを作って」と頼みます。

  2. エージェントがツールを呼び出す

    MCPサーバーがツールの一覧を示し、エージェントがその中から1つを選びます。

  3. サーバーがFigmaと通信する

    ホスト型サービス、デスクトップアプリ、REST API、プラグインのいずれかを通じて通信します。どれを使うかで、サーバーにできることが決まります。

  4. 結果が返る

    エージェントが結果を読み、次のステップを決めます。

自分のファイルで試す

この4つのステップを実際のファイルで確かめるなら、Mac向けの無料プラグインサーバーであるFigmaMCPを試してください。セットアップは5分ほどです。

  1. アプリをダウンロードして開きます。 Mac用FigmaMCPをダウンロードし、FigmaMCP.dmgを開いて、アプリをApplicationsにドラッグします。そのあとアプリを開きます。

  2. Add to Figmaをクリックします。 アプリのチェックリストが、Figma、Claude Code、Codexの有無を確認します。Add to Figmaをクリックしてください。Figmaが起動中でプラグインが入っていない場合に限り、Figmaが一度だけ再起動します。

  3. エージェントを再起動します。 Claude CodeやCodexが起動中なら、いったん終了して起動し直し、新しいツールを読み込ませます。

  4. ファイルでプラグインを開きます。 Figmaデスクトップアプリでファイルを開き、Plugins › Development › FigmaMCPを選びます。パネルに接続中のファイルが表示されます。エージェントに編集させるには、パネルの「AI can edit this file」（AIがこのファイルを編集できる）スイッチをオンにしておく必要があります。

まずは読み取りを頼んでみましょう。次の文を貼り付けます：「選択中のフレームにあるテキストレイヤーを、フォントとサイズ付きで一覧にして」。読み取りではファイルは変わらないので、最初のテストに向いています。

詳しい手順はClaude CodeでFigmaファイルを5分で編集するをご覧ください。

主な種類

Figma MCPサーバーの種類
種類接続先読み取り編集
FigmaのリモートサーバーFigmaのホスト型サービスはいはい（キャンバスへの書き込み、ベータ）
FigmaのデスクトップサーバーFigmaデスクトップアプリのDev Modeはいいいえ
REST APIサーバー（Framelinkなど）トークンを使ったFigma REST APIはいいいえ
プラグインサーバー（FigmaMCPなど）Figmaデスクトップアプリ内のプラグインはいはい

Figmaに関する情報はFigmaのMCPドキュメントとデスクトップサーバーのガイドにもとづきます（2026年11月25日確認）。内容は変わる可能性があります。

FigmaMCPの位置づけ

FigmaMCPはMac向けの無料プラグインサーバーです。Figmaデスクトップアプリで開いているファイルを対象に動き、APIトークンは不要で、FigmaのMCP呼び出し上限も使いません。すべてのツールを見るか、ローカルとリモートのサーバーの比較をご覧ください（いずれも英語）。

最初に知っておきたいこと

  • 現在はmacOS専用です。
  • Figmaデスクトップアプリが必要です。ブラウザ版では動きません。
  • FigmaMCPはFigma Communityにはありません。Macアプリがプラグインをインストールします。
  • アクセシビリティを許可しない場合は、ファイルごとに一度プラグインを開き（Plugins、Development、FigmaMCP）、エージェントが編集している間は開いたままにしてください。
  • Dev ModeなどFigma自体の機能は含まれません。

よくある質問

Figma MCPサーバーとFigmaプラグインは同じものですか？
いいえ。プラグインはFigmaの中で動き、MCPサーバーはエージェントにツールを提供します。FigmaMCPはその両方を使います。サーバーがエージェントに応え、プラグインがFigmaの中で操作します。
Figma MCPは無料ですか？
サーバーによります。Figma自身のサーバーには、プランとシートごとの上限があります。FigmaMCPは無料です。詳しくは料金ページをご覧ください。
エージェントはデザインをモデルに送りますか？
エージェントが読み取った内容は、そのエージェントのモデル提供元に送られ、提供元の規約に従って扱われます。FigmaMCPがデザインの内容を私たちに送ることはありません。
