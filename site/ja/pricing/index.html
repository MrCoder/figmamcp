Figma MCPの料金：FigmaMCPは現在無料です

言語： English · 简体中文 · 日本語

FigmaMCPは現在無料です。料金はかからず、アカウント登録もFigma APIトークンも必要ありません。将来は価格を設定する可能性があり、ずっと無料であるとはお約束できません。一方、Figma公式のMCPサーバーはFigmaのプランに含まれ、呼び出し回数の上限はシートによって決まります。このページでは両方を紹介します。

FigmaMCPの使い方

購入も登録も必要ありません。ダウンロードから、ファイルについての最初の回答を得るまで、4つのステップです。

  1. アプリをダウンロードして開きます。 Mac用FigmaMCPをダウンロードし、FigmaMCP.dmgを開いて、アプリをApplicationsにドラッグします。そのあとアプリを開きます。

  2. Add to Figmaをクリックします。 アプリのチェックリストが、Figma、Claude Code、Codexの有無を確認します。Add to Figmaをクリックしてください。Figmaが起動中でプラグインが入っていない場合に限り、Figmaが一度だけ再起動します。

  3. エージェントを再起動します。 Claude CodeやCodexが起動中なら、いったん終了して起動し直し、新しいツールを読み込ませます。

  4. ファイルでプラグインを開きます。 Figmaデスクトップアプリでファイルを開き、Plugins › Development › FigmaMCPを選びます。パネルに接続中のファイルが表示されます。エージェントに編集させるには、パネルの「AI can edit this file」（AIがこのファイルを編集できる）スイッチをオンにしておく必要があります。

まずは読み取りを頼んでみましょう。次の文を貼り付けます：「選択中のフレームにあるテキストレイヤーを、フォントとサイズ付きで一覧にして」。読み取りではファイルは変わらないので、最初のテストに向いています。

詳しい手順はClaude CodeでFigmaファイルを5分で編集するをご覧ください。

Figma公式MCPサーバーとの比較

Figma自身のMCPサーバーはホスト型のサービスで、シートとプランごとに呼び出し回数の上限があります。FigmaMCPは仕組みが違います。Mac上のローカルサーバーが、Figmaデスクトップアプリ内のプラグインと通信します。FigmaのMCPサーバーを呼び出さないため、Figmaの読み取り上限はこの仕組みに関係しません。

書き込みは別の話です

Figmaによると、書き込みツールはこれらの読み取り上限の対象外です。Figmaのサーバーでキャンバスに書き込むには、Professional以上のプランと編集権限が必要です。Figmaは、ベータ期間中は無料で、今後は使用量に応じた課金にする予定だとしています。詳しくはFigmaのwrite to canvasページ（2026年11月25日確認）か、公式の条件とローカルの選択肢を並べたFigma MCP write to canvas（英語）をご覧ください。

つまり、公式サーバーの話は読み取り上限だけではありません。私たちもそうは主張していません。2つのツールは仕組みが異なるので、自分の作業に合うほうを選んでください。プランごとの詳細はFigma MCP on the free plan、Figma MCP Starter plan limit、Figma MCP limit reached（いずれも英語）にあります。

最初に知っておきたいこと

  • 現在はmacOS専用です。
  • Figmaデスクトップアプリが必要です。ブラウザ版では動きません。
  • FigmaMCPはFigma Communityにはありません。Macアプリがプラグインをインストールします。
  • アクセシビリティを許可しない場合は、ファイルごとに一度プラグインを開き（Plugins、Development、FigmaMCP）、エージェントが編集している間は開いたままにしてください。
  • Dev ModeなどFigma自体の機能は含まれません。

FigmaMCPは独立したソフトウェアです。Figmaデスクトップアプリの利用には、引き続きFigmaの利用規約が適用されます。

よくある質問

FigmaMCPは無料ですか？
はい、現在は無料です。料金も登録もAPIトークンも不要です。将来価格を決める可能性があり、ずっと無料であるとはお約束できません。
Figma公式のMCPサーバーは無料ですか？
Figmaはシートとプランごとの呼び出し上限を公表しています。また、キャンバスへの書き込みにはProfessional以上のプランと編集権限が必要で、ベータ期間中は無料、今後は使用量に応じた課金になる予定だとしています。最新の条件は、上のリンク先のFigmaのページで確認してください。
Enterpriseプランでは Figma MCP の費用はいくらですか？
Figma の MCP サーバーは Figma のプランに含まれます。Enterprise で変わるのは読み取りの上限で、Full または Dev シートは1日600回・1分20回まで、View または Collab シートは月20回までです（2026-11-22 に Figma の掲載内容を確認）。書き込みツールは対象外です。全プランの上限はFigma MCP のレート制限をご覧ください。FigmaMCP はどのプランでも無料で、呼び出し回数の割り当てはありません。Enterprise アカウントではまだテストしていません。組織で開発用プラグインを実行できるかどうかが重要なので、まず1つのファイルで試してください。
Figmaの読み取り上限はFigmaMCPにも適用されますか？
いいえ。FigmaMCPはFigmaのMCPサーバーを呼び出しません。すでに開いているデスクトップアプリの中で、Plugin APIを通じて動作します。
FigmaMCPを使うのに、Figmaへの支払いは必要ですか？
FigmaMCPはFigmaデスクトップアプリで開発版プラグインを動かします。そのため重要なのは、お使いのアカウントでそのファイルに開発版プラグインを実行できるかどうかです。すべてのプランを試したわけではありません。まず1つのファイルで試してください。
