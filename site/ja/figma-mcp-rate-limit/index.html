Figma MCP レート制限（プラン別）

言語： English · 简体中文 · 日本語

Figma公式のMCPサーバーには、アカウントごとの呼び出し回数の上限があります。上限の対象は、Figmaからデータを読み取るツールです。Figmaファイルに書き込むツールなど、一部のツールは対象外です。このページでは、Figmaが公表しているプラン別の上限（2026-11-22確認）と、それがエージェントによるデザイン作業で何を意味するかをまとめます。

作業で何が起きるか

  • エージェントの作業のうち上限にかかるのは「見る」部分です。ページを読み、次にそのフレーム、さらにテキストやスタイルを読む作業は、何かを変更する前に読み取り呼び出しを使います。
  • 主に書き込む作業は枠をあまり使いません。主に読み取る作業は、すぐに枠を使います。
  • 上限に達したら、読み取りを少なく、狭い範囲にするようエージェントに頼んでください。ファイル全体ではなく、1つのフレームを指定します。そのほかの方法はFigma MCP limit reached（英語）のページにまとめています。

FigmaMCPとの違い

FigmaMCPは、ローカルサーバーと、Figmaデスクトップアプリ内のプラグインからなるMacアプリです。エージェントはローカルサーバーと通信し、プラグインがMac上でFigmaのPlugin APIを通じて開いているファイルを読み取り・編集します。FigmaのMCPサーバーは呼び出さないため、FigmaのMCPレート制限はこの仕組みに関係しません。また、FigmaMCP独自の呼び出し回数の上限もありません。

ただし、Figmaのルールがすべてなくなるわけではありません。あなたのアカウントでファイルに開発用プラグインを実行できるかどうかはFigmaが決めることで、私たちはすべてのプランを試したわけではありません。これを前提に計画を立てる前に、まず1つのファイルで試してください。Official Figma MCP vs FigmaMCP（英語）と料金もご覧ください。

最初に知っておきたいこと

  • 現在はmacOS専用です。
  • Figmaデスクトップアプリが必要です。ブラウザ版では動きません。
  • FigmaMCPはFigma Communityにはありません。Macアプリがプラグインをインストールします。
  • アクセシビリティを許可しない場合は、ファイルごとに一度プラグインを開き（Plugins、Development、FigmaMCP）、エージェントが編集している間は開いたままにしてください。
  • Dev ModeなどFigma自体の機能は含まれません。

よくある質問

Figma MCP のレート制限はどれくらいですか？
シートとプランによります。2026-11-22時点で、Figmaは View または Collab シートについて全プランで月20回まで、Full または Dev シートについて Professional で1日200回・1分あたり10回、Organization で1日200回・1分あたり15回、Enterprise で1日600回・1分あたり20回までとしています。
Figma MCP の書き込み呼び出しは上限に数えられますか？
いいえ。Figmaによると、上限はFigmaからデータを読み取るツールに適用され、Figmaファイルに書き込むツールなど一部のツールは対象外です。出典：Figmaの rate limits and access ページ（2026-11-22確認）。
どの呼び出しが上限にかかりますか？
読み取りツールです。たとえば get_design_context、get_metadata、get_screenshot です。編集する前にデザインを確認するエージェントは、まずこれらを使います。
FigmaMCPに呼び出し回数の上限はありますか？
FigmaMCP独自の呼び出し回数の上限はなく、FigmaのMCPサーバーも呼び出しません。Figmaデスクトップアプリ内のプラグインを通じて動くため、ファイルへの既存のアクセス権が必要で、編集するには編集権限が必要です。
