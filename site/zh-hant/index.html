你的 Agent 編輯你已經打開的 Figma 檔案。

語言： English · 简体中文 · 繁體中文 · 日本語 · Polski · Français · Deutsch · 한국어 · Українська

FigmaMCP 是一個免費的本機工具，讓 Claude Code 或 Codex 讀取並編輯你在 Figma 桌面版中打開的檔案。它透過 Figma 的外掛程式 API 在你的 Mac 上執行，所以沒有呼叫次數需要盯著。

實際效果

它能做什麼

用日常語言告訴 Agent 你想要什麼。它會先讀取打開檔案的結構，再直接在這個檔案裡修改，你可以看著改動發生。

讀取

頁面、畫框、圖層、文字、元件、變數和樣式 —— 來自你眼前這個檔案。

編輯

建立和修改畫框、文字、形狀、元件和實例、自動版面配置、填色、邊框和效果。

批次應用

一次請求裡重新命名、改樣式或改寫很多圖層，例如把所有提到舊產品名稱的文字圖層一起改掉。

保持在邊界內

每次編輯都必須準確指明目標；批次編輯裡只要有一項無效，就一項都不會改；外掛程式裡的一個開關可以讓檔案變成只能讀取。

怎麼用

  1. 下載並打開 App

    下載 Mac 版 FigmaMCP 並打開它。它常駐在選單列。

  2. 點選 Add to Figma

    只有 Figma 正在執行且還沒安裝外掛程式時，才會重新啟動一次。你也可以允許「輔助使用」權限，這樣 FigmaMCP 就能替你的 Agent 打開外掛程式。

  3. 讓 Agent 去改

    讓 Claude Code 或 Codex 修改你打開的檔案。不需要匯入任何東西，不需要貼程式碼，也不需要選擇連接埠。

你應該先知道的事

  • 目前僅支援 macOS。
  • 需要 Figma 桌面版，無法在瀏覽器中執行。
  • FigmaMCP 不在 Figma Community 裡，Mac App 會替你安裝外掛程式。
  • 如果不允許「輔助使用」，請在每個檔案裡手動打開一次外掛程式（Plugins、Development、FigmaMCP），並在 Agent 編輯期間保持它打開。
  • Dev Mode 等屬於 Figma 本身的功能不包含在內。

常見問題

FigmaMCP 真的免費嗎？
是的。免費，沒有付費方案。它不會呼叫 Figma 託管的 MCP 伺服器，所以 Figma 按座位計算的呼叫限制不適用於它。你打開的檔案仍然受你自己的 Figma 方案與 Figma 條款約束。
它和 Figma 官方 MCP 伺服器有什麼不同？
Figma 官方伺服器由 Figma 自己提供，可搭配許多 MCP 用戶端使用。在較低階的方案上，它的讀取呼叫有上限，畫布寫入仍在 beta，而且在草稿之外需要 Full 席位。FigmaMCP 在你的 Mac 上執行，透過你已開啟檔案裡的外掛程式運作，不需要 API 權杖，也沒有呼叫配額。它適用於 Claude Code 和 Codex，僅支援 macOS。詳見完整比較。
兩個人同時開啟同一個檔案，Agent 編輯的是誰的 Figma？
是 Agent 所在那台 Mac 上的 Figma 桌面版。Agent 與該應用程式中的外掛程式通訊，所以是以那個人的身分編輯，他需要有該檔案的編輯權限。其他人會像看到任何其他編輯一樣即時看到變更。如果兩個人在同一時刻修改同一個圖層，由 Figma 自己的多人同步來解決：修改不同屬性時兩處變更都會保留，修改同一屬性時以最後一次變更為準。FigmaMCP 自己不增加任何合併步驟。
支援 Windows 或 Linux 嗎？
暫時不支援。FigmaMCP 目前僅支援 macOS。
需要 Figma API 權杖嗎？
不需要。FigmaMCP 透過外掛程式 API 和你 Mac 上的 Figma 桌面版通訊，沒有存取權杖需要建立或貼上。
為什麼外掛程式不在 Figma Community 裡？
FigmaMCP 在 Figma Community 之外發布。你不需要手動安裝：Mac App 會替你把它註冊到 Figma，之後它會出現在 Plugins、Development 底下。
支援哪些 Agent？
Claude Code 和 Codex 是經過測試的目標，Mac App 會替你連接它們。
Agent 會不會毀掉我的檔案？
改動只會發生在外掛程式已打開、且「AI can edit this file」開關為開啟的檔案裡；關掉開關，AI 就只能讀取。每次編輯都必須準確指明目標圖層，批次編輯會在改動前先檢查。它仍然是一個編輯工具：請像檢查同事的工作一樣檢查結果，並善用 Figma 的版本歷史。
它會向 Figma 的伺服器發送請求嗎？
不會。FigmaMCP 不會呼叫 Figma 的伺服器或 REST API。你的 Agent 和本機的 MCP 伺服器通訊，MCP 伺服器再透過 localhost 和 Figma 桌面版裡的外掛程式通訊，外掛程式透過 Plugin API 在 App 內讀取與編輯檔案。你的改動之後會像你自己編輯一樣，透過 App 的正常同步到達 Figma 的雲端。外掛程式自身發出的請求不帶檔案內容：每次外掛程式啟動時，會向 figmamcp.dev 和 Google Analytics 傳送一次載入計數，帶上外掛程式版本與一個隨機安裝 ID；還會把按工具名稱統計的呼叫次數批次傳送給 figmamcp.dev，不帶任何內容。
我的設計會離開我的電腦嗎？
FigmaMCP 本身不會把檔案內容傳送到任何地方。不過你的 Agent 會讀取 FigmaMCP 回傳的內容，並按它自己模型供應商的條款傳送出去，詳見隱私頁面。
這是 Figma 官方做的嗎？
不是。FigmaMCP 與 Figma, Inc. 沒有關聯，也未獲得其認可。FigmaMCP 是 Neo Product LLC 的 figma-edit-mcp 的分支。

校驗下載

App 需要 macOS 14 或更新版本，支援 Intel 和 Apple 晶片的 Mac。磁碟映像檔約 155 MB。如果 /download 很慢或打不開，請從 GitHub 發布頁面下載 FigmaMCP.dmg，或用固定連結：curl -L -O https://github.com/MrCoder/figmamcp-releases/releases/latest/download/FigmaMCP.dmg。發布頁面在每個檔案旁邊會顯示一個 sha256: 值，把它和你下載的檔案比較：

shasum -a 256 ~/Downloads/FigmaMCP.dmg

兩個值不一致時，刪除檔案並重新下載。

安裝程式會改動什麼

App 的清單只會寫入下面這些位置，已經完成的步驟會跳過。

安裝程式寫入的檔案和設定
位置內容
/Applications/FigmaMCP.appApp 本身。
~/.figmamcp/versions/<版本> 和 ~/.figmamcp/current每個版本的 MCP 伺服器、中繼、外掛程式和 skill。current 是指向目前版本的符號連結。config.json 記錄中繼連接埠，logs/ 存放中繼日誌。
~/.claude.json用 claude mcp add 新增的使用者層級 MCP 項目 figmamcp。只有裝了 Claude Code 時才會新增。
~/.codex/config.toml用 codex mcp add 新增的 MCP 項目 figmamcp。只有裝了 Codex 時才會新增。
~/.claude/skills/figmamcp 和 ~/.codex/skills/figmamcpFigmaMCP skill，給 AI 看的使用說明。如果其中一個是指向別處的連結，就不會改動它。
~/Library/LaunchAgents/com.figmamcp.relay.plist登入時啟動本機中繼的 LaunchAgent。中繼監聽 localhost 的 3155 連接埠；被佔用時改用 3156 到 3158 中第一個空閒的連接埠。
Figma 的外掛程式列表把 FigmaMCP 開發版外掛程式加入 ~/Library/Application Support/Figma/settings.json，原始檔案會保存在旁邊的 settings.json.figmamcp-backup。

舊的同類設定不會被改動。如果你以前裝過 FigmaMCP 派生自的上游專案，它的 MCP 項目、中繼和外掛程式都會保持原樣。區分方法：FigmaMCP 的工具名稱以 mcp__figmamcp__ 開頭，外掛程式在 Plugins → Development → FigmaMCP；其他前綴的工具不屬於 FigmaMCP。不想讓兩者並存時，用 claude mcp list 或 codex mcp list 找到舊項目，再用對應的 mcp remove 刪掉。

卸載或回退

回退到舊版本：從版本列表下載舊版 FigmaMCP.dmg，取代「應用程式」裡的 App，打開它並按清單操作，然後重新啟動 Claude Code 或 Codex。裝過的舊版本會保留在 ~/.figmamcp/versions 裡。

卸載：先在 Figma 裡選 Plugins → Development → Manage plugins in development，移除 FigmaMCP。然後在終端機執行下面的指令。沒有用某個 AI 就跳過對應的 claude 或 codex 那一行。最後兩行會刪除 App 和所有 FigmaMCP 版本，無法復原。

osascript -e 'quit app "FigmaMCP"'
launchctl bootout gui/$(id -u)/com.figmamcp.relay
rm ~/Library/LaunchAgents/com.figmamcp.relay.plist
claude mcp remove figmamcp -s user
codex mcp remove figmamcp
rm -rf ~/.claude/skills/figmamcp ~/.codex/skills/figmamcp
rm -rf /Applications/FigmaMCP.app ~/.figmamcp

之後重新啟動 Claude Code 或 Codex，讓它不再載入這個工具。

隱私

網站和外掛程式會統計使用情況：網站使用 Google Analytics，外掛程式每次打開都會送出一個事件，只帶外掛程式版本號和一個隨機的安裝 ID；外掛程式還會分批送出工具呼叫次數（依工具名稱統計成功和失敗次數），不帶檔案名稱、檔案金鑰、圖層名稱或設計內容。完整說明見隱私頁面。
