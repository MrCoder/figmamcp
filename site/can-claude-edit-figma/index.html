Can Claude edit Figma files?

Yes. Claude Code can create and change layers in the Figma file you have open, if it can reach the file. FigmaMCP gives it that reach: a small local server on your Mac and a plugin inside the Figma desktop app. Claude talks to the server, the server talks to the plugin, and the plugin edits the file.

How Claude Code reaches the file

FigmaMCP connects Claude Code to Figma in four steps. You download the Mac app and click Add to Figma. The app installs the plugin and registers FigmaMCP with Claude Code. You restart Claude Code if it was running. Then you open the file in the Figma desktop app and ask for a change. Claude reads first with page_info and node_info, then writes. You need no Figma API token.

What Claude cannot do

FigmaMCP stops Claude in these cases. Claude cannot edit a file where the plugin is closed or where the AI can edit this file switch is off. In that case it can only read. It cannot edit locked layers, assets that come from a shared library, or the structure inside a component instance. It also cannot use Figma features that belong to Figma itself, such as Dev Mode. The result is only as good as your prompt, so review it and keep Figma version history on.

When Claude gets an error

FigmaMCP returns a structured error when it refuses an edit, and Claude can act on it. If the layer name does not match, Claude refreshes it with node_info and tries again. If the plugin is not open, Claude gets PLUGIN_PEER_UNAVAILABLE and asks you to open it. If the edit switch is off, Claude gets READ_ONLY_MODE and tells you. See troubleshooting for the full list.

Claude Code or Claude Desktop?

FigmaMCP works with Claude Code and Codex. It does not list Claude Desktop as a supported client. See Figma MCP for Claude Code for setup, and what the agent can write for the full list.

Questions

Can Claude create a design from scratch in Figma?
It can build frames, shapes, text and components and lay them out with auto layout. Treat the first result as a draft and review it.
Do I need a paid Figma plan?
FigmaMCP does not use Figma’s hosted MCP server, so its call allowance is not involved. Whether your account can run a development plugin is up to Figma. We have not tested every plan.
Does Claude see my whole account?
No. It works on the one file where the plugin is open.
Does Claude need a Figma API token?
No. FigmaMCP works through the Figma desktop app on your Mac, so there is no token to create.
