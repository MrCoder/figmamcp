A Figma MCP alternative that runs on your Mac

FigmaMCP edits the file open in your Figma desktop app through Figma’s Plugin API, on your own Mac. It does not call Figma’s MCP server, so Figma’s per-seat call limits do not apply to it. It is not the only Figma MCP alternative, and for some jobs another tool fits better. The table compares five options, as of November 9, 2026.

How to try FigmaMCP

If FigmaMCP fits your job, you can test it on a real file in about five minutes.

  1. Download the app and open it. Download FigmaMCP for Mac, open FigmaMCP.dmg and drag the app to Applications. Then open the app.

  2. Click Add to Figma. The app’s checklist checks for Figma, Claude Code and Codex. Click Add to Figma. Figma restarts once, and only if it was running and the plugin was missing.

  3. Restart your agent. If Claude Code or Codex is running, quit it and start it again, so it loads the new tools.

  4. Open the plugin in your file. Open the file in the Figma desktop app, then choose Plugins › Development › FigmaMCP. The panel shows the connected file. Its AI can edit this file switch must be on before your agent can edit.

Then ask your agent for a read first. Paste this: “List the text layers in the selected frame, with their font and size.” A read cannot change the file, so it is a safe first test.

Trade-offs of FigmaMCP, plainly

  • It runs on macOS only, and only with the Figma desktop app. It does not run in the browser.
  • It works with Claude Code and Codex. Other MCP clients are not supported.
  • It is not on Figma Community. The Mac app installs the plugin for you.
  • If you do not allow Accessibility, open the plugin once in each file (Plugins, Development, FigmaMCP) and leave it open while your agent edits.
  • It does not include Figma features such as Dev Mode, and it does not generate code.

Questions

Which one should I pick for read-only work?
If you only need an agent to read a design, such as turning a frame into code, a read-only tool like Framelink is built for that. FigmaMCP is for when you want the agent to change the file.
Are these tools compatible with each other?
They are separate. Do not run two that both try to edit the same file at once; use one at a time.
Is the table complete?
No. It states only what each project says about itself at a glance, as of November 9, 2026. Check each README before deciding.
