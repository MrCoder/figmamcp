Figma MCP Starter plan: limits and options

On the Figma Starter plan, a View or Collab seat gets up to 20 Figma MCP read calls per month. Figma’s rate-limit table lists no Full or Dev seat limit for Starter, and Starter is not on the list of plans that can write to the canvas. Below are the details from Figma’s docs, checked 2026-11-13, and a free local tool that does not use these calls.

Figma’s pages are the authority and they may change. Figma says the limits apply to tools that read data from Figma, and that tools which write to Figma files are exempt from them.

What the Starter rate limit means in practice

Twenty calls a month is a small allowance for an agent. An agent that explores a design before it acts can make several read calls for one task. That is why a Starter seat is a way to try reading a design with the official server, and not a basis for a daily workflow. Figma’s page says that to get higher limits you move to a Professional, Organization or Enterprise plan with a Full or Dev seat. That is a plan decision for you and your team.

A separate free local tool

FigmaMCP is a free Mac app and it is not made by Figma. It works with Claude Code and Codex only, on macOS, and it needs the Figma desktop app. The Mac app adds the plugin to Figma and connects Claude Code and Codex. It needs no API token.

FigmaMCP reads and edits the file open in Figma desktop through a local server and a plugin. It has no call quota of its own, and it does not use Figma’s MCP server. You need whatever access you already have to the file in Figma, and edit access to edit. We have not tested every plan, so try it on one file before you plan around it.

The plugin has an “AI can edit this file” switch. Each edit names its target layer, and errors come back in a structured form.

How to try FigmaMCP on a Starter file

Testing it on one Starter file takes four steps and about five minutes.

  1. Download the app and open it. Download FigmaMCP for Mac, open FigmaMCP.dmg and drag the app to Applications. Then open the app.

  2. Click Add to Figma. The app’s checklist checks for Figma, Claude Code and Codex. Click Add to Figma. Figma restarts once, and only if it was running and the plugin was missing.

  3. Restart your agent. If Claude Code or Codex is running, quit it and start it again, so it loads the new tools.

  4. Open the plugin in your file. Open the file in the Figma desktop app, then choose Plugins › Development › FigmaMCP. The panel shows the connected file. Its AI can edit this file switch must be on before your agent can edit.

Then ask your agent for a read first. Paste this: “List the text layers in the selected frame, with their font and size.” A read cannot change the file, so it is a safe first test.

What you should know first

  • macOS only for now.
  • It needs the Figma desktop app. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin for you.
  • If you do not allow Accessibility, open the plugin once in each file (Plugins, Development, FigmaMCP) and leave it open while your agent edits.
  • Features that belong to Figma itself, such as Dev Mode, are not included.

Questions

What is the Figma MCP Starter plan limit?
Figma’s rate-limit page says a View or Collab seat gets up to 20 calls per month on every plan, including Starter. Its table lists no Full or Dev limit for Starter. Checked 2026-11-13.
What is the Figma MCP Starter plan rate limit per minute?
Figma’s table gives a per-minute figure only for Full and Dev seats on Professional, Organization and Enterprise. For Starter it lists the monthly figure for View and Collab seats only.
Does the Starter limit apply to writing?
Figma says the limits apply to tools that read data, and that tools which write to Figma files are exempt. Separately, Figma lists Professional, Education, Organization and Enterprise for writing to the canvas, and does not list Starter.
Does FigmaMCP have a Starter limit?
FigmaMCP has no call quota of its own and does not call Figma’s MCP server. It works through a plugin in your Figma desktop app, so you need your existing access to the file, and edit access to edit.
