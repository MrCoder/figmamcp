이미 열려 있는 Figma 파일을 에이전트가 편집합니다.

언어: English · 简体中文 · 繁體中文 · 日本語 · Polski · Français · Deutsch · 한국어 · Українська

FigmaMCP는 무료로 제공되는 로컬 도구로, Claude Code나 Codex가 Figma 데스크톱 앱에서 열려 있는 파일을 읽고 편집할 수 있게 해줍니다. Mac에서 Figma의 Plugin API를 통해 동작하므로 호출 횟수를 신경 쓸 필요가 없습니다.

Mac용 다운로드 Version 0.1.25 macOS 14 이상 · Intel 및 Apple Silicon · 약 155MB

다운로드가 느리거나 막혔나요? GitHub 릴리스 페이지에서 FigmaMCP.dmg를 받으세요. SHA-256 확인.

다운로드가 시작되었습니다. FigmaMCP.dmg를 열고 앱을 Applications로 끌어다 놓으세요. 설치 가이드.

선택 사항입니다. 메일은 몇 번만 보내며, 모든 메일에 구독 취소 링크가 있습니다. 개인정보 보호.

현재는 macOS에서만 지원됩니다. Figma 데스크톱 앱이 필요합니다. 무료이며 로컬에서 동작합니다.

실제로 보기

할 수 있는 일

원하는 것을 평범한 말로 에이전트에게 알려주세요. 에이전트는 열려 있는 파일의 구조를 읽은 다음, 같은 파일에서 바로 편집을 수행하며, 변화를 바로 확인할 수 있습니다.

읽기

눈앞의 파일에서 페이지, 프레임, 레이어, 텍스트, 컴포넌트, 변수, 스타일을 읽습니다.

편집

프레임, 텍스트, 도형, 컴포넌트와 인스턴스, 오토 레이아웃, 채우기, 테두리, 효과를 만들고 바꿉니다.

한 번에 여러 곳에 적용

한 번의 요청으로 여러 레이어의 이름이나 스타일을 바꾸거나 내용을 다시 쓸 수 있습니다. 예를 들어 옛 제품명이 적힌 모든 텍스트 레이어를 한꺼번에 고칠 수 있습니다.

안전한 범위 안에서

모든 편집은 대상을 정확히 지정해야 하며, 일괄 편집에 유효하지 않은 항목이 하나라도 있으면 아무것도 바뀌지 않습니다. 플러그인의 스위치 하나로 파일을 읽기 전용으로 만들 수도 있습니다.

사용 방법

  1. 앱을 다운로드하고 열기

    Mac용 FigmaMCP를 다운로드해서 열어보세요. 메뉴 막대에 상주합니다.

  2. Add to Figma 클릭

    Figma가 실행 중이고 플러그인이 아직 없을 때만, 한 번 재시작됩니다. 손쉬운 사용(Accessibility) 권한을 허용하면 FigmaMCP가 AI를 대신해 플러그인을 열 수 있습니다.

  3. 에이전트에게 요청

    Claude Code나 Codex에게 열려 있는 파일을 바꿔달라고 요청하세요. 가져올 것도, 붙여넣을 코드도, 선택할 포트도 없습니다.

먼저 알아두면 좋은 점

  • 현재는 macOS에서만 지원됩니다.
  • Figma 데스크톱 앱이 필요합니다. 브라우저에서는 동작하지 않습니다.
  • FigmaMCP는 Figma Community에 없습니다. Mac 앱이 대신 플러그인을 설치합니다.
  • 손쉬운 사용 권한을 허용하지 않는다면, 각 파일에서 플러그인(Plugins, Development, FigmaMCP)을 한 번 열고, 에이전트가 편집하는 동안 열어두세요.
  • Dev Mode처럼 Figma 자체에 속한 기능은 포함되지 않습니다.

자주 묻는 질문

FigmaMCP는 정말 무료인가요?
네. 무료이며 유료 등급이 없습니다. Figma가 호스팅하는 MCP 서버를 호출하지 않으므로 Figma의 시트당 호출 제한이 적용되지 않습니다. 여는 파일에는 여전히 사용자 자신의 Figma 요금제와 Figma의 약관이 적용됩니다.
Figma 공식 MCP 서버와는 무엇이 다른가요?
Figma 공식 서버는 Figma가 직접 제공하며 많은 MCP 클라이언트에서 작동합니다. 요금제가 낮으면 읽기 호출에 상한이 있고, 캔버스 쓰기는 베타이며 초안 밖에서는 Full 좌석이 필요합니다. FigmaMCP는 열어 둔 파일의 플러그인을 통해 Mac에서 실행되며, API 토큰도 호출 쿼터도 없습니다. Claude Code와 Codex에서 작동하며 macOS 전용입니다. 전체 비교를 참고하세요.
두 사람이 같은 파일을 열어 둔 경우, 에이전트는 누구의 Figma를 편집하나요?
에이전트가 실행되는 Mac의 Figma 데스크톱 앱입니다. 에이전트는 그 앱의 플러그인과 통신하므로 그 사람 자격으로 편집하며, 그 사람에게 파일 편집 권한이 있어야 합니다. 다른 사람들에게는 일반 편집과 똑같이 변경 사항이 실시간으로 보입니다. 두 사람이 같은 순간에 같은 레이어를 바꾸면 Figma 자체의 멀티플레이어 동기화가 정리합니다. 서로 다른 속성의 변경은 둘 다 유지되고, 같은 속성은 마지막 변경이 적용됩니다. FigmaMCP는 자체 병합 단계를 추가하지 않습니다.
Windows나 Linux에서도 쓸 수 있나요?
아직은 아닙니다. FigmaMCP는 현재 macOS만 지원합니다.
Figma API 토큰이 필요한가요?
아니요. FigmaMCP는 Mac의 Figma 데스크톱 앱과 Plugin API로 통신하므로, 만들거나 붙여넣을 액세스 토큰이 없습니다.
플러그인이 Figma Community에 없는 이유는 무엇인가요?
FigmaMCP는 Figma Community 밖에서 배포됩니다. 직접 설치할 필요가 없습니다. Mac 앱이 대신 Figma에 등록해 주며, 이후 Plugins, Development 아래에 나타납니다.
어떤 에이전트와 함께 쓸 수 있나요?
Claude Code와 Codex가 테스트된 대상이며, Mac 앱이 대신 연결해 줍니다.
에이전트가 파일을 망가뜨릴 수 있나요?
편집은 플러그인이 열려 있고 AI can edit this file 스위치가 켜져 있는 파일에만 적용됩니다. 스위치를 끄면 AI는 읽기만 할 수 있습니다. 모든 편집은 대상 레이어를 정확히 지정해야 합니다. 일괄 편집은 어떤 변경이든 적용되기 전에 검사됩니다. 그래도 편집 도구이므로, 동료의 작업을 검토하듯 결과를 확인하고 Figma의 버전 기록도 활용하세요.
Figma의 서버에 요청을 보내나요?
아니요. FigmaMCP는 Figma의 서버나 REST API를 호출하지 않습니다. 에이전트는 로컬 MCP 서버와 통신하고, 이 서버는 localhost를 통해 Figma 데스크톱 앱 안의 플러그인과 통신하며, 플러그인은 앱 안의 Plugin API로 파일을 읽고 편집합니다. 사용자의 편집 내용은 그 뒤 자신이 직접 편집한 것과 똑같이 앱의 일반적인 동기화를 통해 Figma의 클라우드에 반영됩니다. 플러그인 자체가 보내는 요청에는 파일 내용이 전혀 들어가지 않습니다. 플러그인을 시작할 때마다 플러그인 버전과 임의의 설치 ID를 담은 실행 1건을 figmamcp.dev와 Google Analytics로 보내고, 도구 이름별 호출 횟수를 내용 없이 모아 figmamcp.dev로 보냅니다.
내 디자인이 내 컴퓨터 밖으로 나가나요?
FigmaMCP 자체는 파일 내용을 어디로도 보내지 않습니다. 다만 에이전트는 FigmaMCP가 반환한 내용을 읽어서, 자신이 사용하는 모델 제공자의 약관에 따라 그쪽으로 전송합니다. 자세한 내용은 개인정보 보호 페이지를 참고하세요.
이건 Figma가 만든 건가요?
아닙니다. Figma, Inc.와 제휴하거나 Figma의 승인을 받은 제품이 아닙니다. FigmaMCP는 Neo Product LLC의 figma-edit-mcp를 포크한 것입니다.

FigmaMCP 받기

무료입니다. FigmaMCP 계정도, Figma API 토큰도 필요 없습니다. 에이전트가 지금 열어 둔 파일을 바로 편집합니다.
