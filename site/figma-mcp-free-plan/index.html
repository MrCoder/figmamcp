Figma MCP on the free plan

On the free Starter plan you cannot hold a Full or Dev seat, and those are the seats with a practical daily allowance. What is left is a View or Collab seat, which gets 20 Figma MCP read calls per month, and writing to the canvas needs a Professional plan or above. These are Figma’s published terms as of November 22, 2026, and they may change.

What 20 calls a month buys

Very little for an agent. Looking at one page and a handful of frames can use all 20. So on a free plan, Figma’s hosted MCP server is best treated as a way to try reading a design, not as a daily working tool. The Starter plan limit and rate limit are on their own page: Figma MCP Starter plan limit.

A local option

FigmaMCP is free. It does not use Figma’s hosted MCP server. A small local server on your Mac talks to a plugin running inside the Figma desktop app, and your agent, Claude Code or Codex, talks to that server. Because it goes through the Plugin API on your own machine, Figma’s MCP call allowance is not involved.

Whether it runs for your account depends on Figma letting your account run a development plugin in your file. We have not verified every plan, so try it on one file before you plan around it.

How to try it on the free plan

Setup takes four steps and about five minutes, and none of it uses your 20 read calls.

  1. Download the app and open it. Download FigmaMCP for Mac, open FigmaMCP.dmg and drag the app to Applications. Then open the app.

  2. Click Add to Figma. The app’s checklist checks for Figma, Claude Code and Codex. Click Add to Figma. Figma restarts once, and only if it was running and the plugin was missing.

  3. Restart your agent. If Claude Code or Codex is running, quit it and start it again, so it loads the new tools.

  4. Open the plugin in your file. Open the file in the Figma desktop app, then choose Plugins › Development › FigmaMCP. The panel shows the connected file. Its AI can edit this file switch must be on before your agent can edit.

Then ask your agent for a read first. Paste this: “List the text layers in the selected frame, with their font and size.” A read cannot change the file, so it is a safe first test.

What you should know first

  • macOS only for now.
  • It needs the Figma desktop app. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin for you.
  • If you do not allow Accessibility, open the plugin once in each file (Plugins, Development, FigmaMCP) and leave it open while your agent edits.
  • Features that belong to Figma itself, such as Dev Mode, are not included.

Questions

Can I use the Figma MCP server on the free Starter plan?
Figma’s documentation says Starter has no Full or Dev seat. The seats that remain on a free plan are View and Collab, which get 20 calls per month. Checked November 22, 2026.
Can an agent write to my canvas on a free plan?
Figma says write to canvas requires a Professional plan or above with edit access. It is free during beta and planned to become usage-based.
Will FigmaMCP work on my free plan?
We have not tested every plan, and we will not guess. FigmaMCP uses a development plugin in the desktop app, so what matters is whether your account lets you run one in your file. Install the Mac app and try it on one file; it takes a few minutes.
Is there a catch to “free”?
The cost is setup: macOS and the desktop app. With the Mac app there is nothing to import; without it, you open the plugin once per file and keep it open while your agent works.
