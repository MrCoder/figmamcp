What’s new in FigmaMCP

FigmaMCP ships often. Each release is public at the releases repo; this page summarizes the recent ones in plain words. The app checks for a new version and shows a banner in the plugin when one is out.

Download for Mac Version 0.1.25 macOS 14+ · Intel & Apple Silicon · ~155 MB

FigmaMCP release notes by version
VersionDateWhat changed
0.1.252026-11-22Tool-call counts left by a plugin that closed before it could send them are no longer held until the next start. A plugin that stays open checks every minute and sends them, once, as soon as they are 5 minutes old. Before, a plugin opened again within 5 minutes and then left open did not send them. What is counted has not changed.
0.1.242026-11-22The FigmaMCP relay and the Mac app send anonymous usage events to Mixpanel through figmamcp.dev, without your IP address: plugin opened, AI connected, one event per tool call (tool name, result, error code, duration) and app launched. No file names, layer names or design content. To turn them off, add "telemetry": false to ~/.figmamcp/config.json. See the privacy page.
0.1.232026-11-22The plugin sends its anonymous tool-call counts while it is open: the first call at once, later calls at most once a minute. Counts not yet sent are kept in the plugin’s own Figma storage and sent the next time it opens. It used to wait for 20 calls, 10 minutes or the plugin closing, and the count sent on close was often lost. What is counted has not changed.
0.1.222026-11-21The setup command’s help and its error messages give the command that is inside the Mac app, /Applications/FigmaMCP.app/Contents/Resources/bin/figmamcp. They used to name a download command that does not work.
0.1.212026-11-21The plugin shows a first prompt you can copy. If no AI app has FigmaMCP loaded a few seconds after the plugin connects, it tells you to quit Claude Code or Codex and open it again.
0.1.202026-11-20The Mac app tells you when a newer version is available. The plugin shows an example prompt the first time it is connected. The app sends one anonymous launch count (version and a random app ID, no file contents).
0.1.192026-11-19The plugin panel lists each AI session connected to the file, one row per session: the app and the session name (for example “Claude Code · Redesign settings page”), when it connected and when it last acted. The name stays on your computer.
0.1.182026-11-19Adds a signal for when an AI assistant connects but has not called a tool yet, so that state is distinct from the plugin being open with no assistant attached, and from an assistant that has already used a tool.
0.1.172026-11-18Fixes anonymous usage counts: a batch that included a failed call was not being sent in 0.1.16.
0.1.162026-11-18Usage counts now also record which tool failed and its error code (for example node_delete:NAME_MISMATCH), so failures can be fixed faster.
0.1.152026-11-18The plugin sends anonymous counts of the tool calls it runs: how many worked, how many failed, and how many times each tool was used.
0.1.142026-11-17The plugin now tells you when a newer FigmaMCP is out, with a small dismissable banner linking to this site’s download page.
0.1.132026-11-17FigmaMCP.app carries its own notarization ticket, so it opens on Macs that cannot reach Apple’s servers.
0.1.122026-11-17After connecting, the plugin panel collapses to a small status pill; setup now re-registers the plugin when its files are missing.
0.1.112026-11-17The plugin counts loads per install with a random anonymous ID stored only in the plugin’s local storage.
0.1.102026-11-11FigmaMCP starts counting site visits and plugin loads with Google Analytics, version number only, with a random ID that is never stored.

Older releases and their full notes are on the releases page. Every .dmg is published with a SHA-256 checksum; see verifying your download.

Curious what any of this means for privacy? See the privacy page. Wondering who can see the code? See FigmaMCP's source.
