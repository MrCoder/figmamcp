FigmaMCP is a free, local tool that lets Claude Code or Codex read and edit a live file in the Figma desktop app. It runs on your Mac through Figma’s Plugin API, so there is no call quota to watch. New to Figma MCP? Start with what it is.

See it work

What it does

Tell your agent what you want in plain language. It reads the structure of your open file, then makes the edits for you in the open file, where you can watch them happen.

Read

Pages, frames, layers, text, components, variables and styles from the file in front of you.

Edit

Create and change frames, text, shapes, components and instances, auto layout, fills, strokes and effects.

Apply at scale

Rename, restyle or rewrite many layers in one request, for example every text layer that mentions an old product name.

Stay inside limits

Each edit must name its target exactly, a bulk edit with one invalid item changes nothing, and one switch in the plugin makes the file read-only.

How it works

  1. Download and open the app

    Download FigmaMCP for Mac and open it. It lives in your menu bar.

  2. Click Add to Figma

    Figma restarts once, and only if it was running and the plugin was missing. You can also allow Accessibility so FigmaMCP can open the plugin for your AI.

  3. Ask your agent

    Ask Claude Code or Codex to change your open file. There is nothing to import, no code to paste, and no port to pick.

What you should know first

  • macOS only for now.
  • It needs the Figma desktop app. It does not run in the browser.
  • FigmaMCP is not on Figma Community. The Mac app installs the plugin for you.
  • If you do not allow Accessibility, open the plugin once in each file (Plugins, Development, FigmaMCP) and leave it open while your agent edits.
  • Features that belong to Figma itself, such as Dev Mode, are not included.

Questions

Is FigmaMCP really free?
Yes. It is free and has no paid tier. It makes no calls to Figma’s hosted MCP server, so Figma’s per-seat call limits do not apply to it. Your own Figma plan and Figma’s terms still apply to the file you open.
How is it different from Figma’s official MCP server?
Figma’s official server is first-party and works with many MCP clients. On smaller plans its read calls are capped, and its canvas writes are in beta and need a Full seat outside drafts. FigmaMCP runs on your Mac through a plugin in the file you have open, with no API token and no call quota. It works with Claude Code and Codex, on macOS only. See the full comparison.
If two people have the same file open, whose Figma does the agent edit?
The Figma desktop app on the Mac where the agent runs. The agent talks to the plugin in that app, so it edits as that person, who needs edit access to the file. Everyone else sees the changes live, like any other edit. If two people change the same layer at the same moment, Figma’s own multiplayer sync settles it: changes to different properties both stay, and for the same property the last change wins. FigmaMCP adds no merge step of its own.
Does it work on Windows or Linux?
Not yet. FigmaMCP supports macOS only for now.
Do I need a Figma API token?
No. FigmaMCP talks to the Figma desktop app on your Mac through the Plugin API, so there is no access token to create or paste.
Why is the plugin not on Figma Community?
FigmaMCP is distributed outside Figma Community. You do not install it by hand: the Mac app registers it in Figma for you, and it then appears under Plugins, Development.
Which agents work with it?
Claude Code and Codex are the tested targets, and the Mac app connects them for you.
Can the agent wreck my file?
Edits go only to the file where the plugin is open and its AI can edit this file switch is on; turn the switch off and the AI can only read. Each edit must name its target layer exactly. Bulk edits are checked before any change is made. It is still an editor: review the result as you would a colleague’s work, and use Figma version history.
Does it send requests to Figma’s servers?
No. FigmaMCP makes no calls to Figma’s servers or REST API. Your agent talks to a local MCP server, which talks to the plugin in the Figma desktop app over localhost, and the plugin reads and edits the file through the Plugin API inside the app. Your edits then reach Figma’s cloud the same way your own edits do, through the app’s normal sync. The only requests the plugin itself makes leave out file contents: one load count per plugin start, carrying the plugin version and a random install ID, to figmamcp.dev and Google Analytics, and batched counts of tool calls by tool name, with no content, to figmamcp.dev.
Does my design leave my machine?
FigmaMCP itself sends no file contents anywhere. Your agent, however, reads what FigmaMCP returns and sends it to its own model provider under that provider’s terms. See the privacy page.
Is this made by Figma?
No. Not affiliated with or endorsed by Figma, Inc. FigmaMCP is a fork of figma-edit-mcp by Neo Product LLC.

Agent setup prompt
Install FigmaMCP on this Mac, then make one small edit in my open Figma file. Use only the commands below, and ask me before anything else.

1. Check that `sw_vers -productVersion` is 14 or later and that /Applications/Figma.app exists. If not, stop and tell me.
2. Download and install the app:
   curl -fL -o /tmp/FigmaMCP.dmg https://github.com/MrCoder/figmamcp-releases/releases/latest/download/FigmaMCP.dmg
   hdiutil detach /tmp/figmamcp-dmg 2>/dev/null; hdiutil attach -nobrowse -readonly -mountpoint /tmp/figmamcp-dmg /tmp/FigmaMCP.dmg
   pgrep -x FigmaMCP && osascript -e 'quit app "FigmaMCP"'
   rm -rf /Applications/FigmaMCP.app && ditto /tmp/figmamcp-dmg/FigmaMCP.app /Applications/FigmaMCP.app
   hdiutil detach /tmp/figmamcp-dmg
3. Run /Applications/FigmaMCP.app/Contents/Resources/bin/figmamcp setup and read its output. Exit code 3 means a step still needs doing. If Figma has never been opened, ask me to open it once, then run setup again. If Figma must restart, ask me before you run setup --restart-figma.
4. Ask me to open a file in the Figma desktop app and run Plugins > Development > FigmaMCP. Then run figmamcp doctor from the same folder until it exits 0.
5. Ask me to restart you so you load the figmamcp tools: quit, run claude --continue (Claude Code) or codex resume --last (Codex), and type "continue".
6. Call figmamcp's page_info, then create_text with "Hello from FigmaMCP" on the current page, using the page id and exact name from page_info. If the edit is refused because editing is off, ask me to turn on "AI can edit this file" in the plugin.
