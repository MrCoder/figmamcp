# Site SEO audit, 2026-11-21 (plan item S3)

Scope: every HTML file under `site/`: 64 files. 61 are in the sitemap: the English home page, 8 locale homepages and 52 English pages, including `/tutorials/edit-figma-with-claude-code`. The other 3 are `/404` and `/subscribed`, both `noindex`, and the Google Search Console verification file.

Method: a scratch crawler over the repository HTML, then new checks in `src/mcp_server/tests/siteSeo.test.ts` so the same rules fail CI on a regression. A mutation red-proved each new check (results below).

## Needs owner judgment (not changed)

1. **Thin internal linking.** (Done 2026-11-21 in PR #96: each page now has in-body links from 2 or more indexable pages; a test enforces it.) Six pages have only one inbound link from an indexable page: `/compare/figwright`, `/compare/code-connect`, `/figma-mcp-starter-plan`, `/tools/components`, `/tools/auto-layout` and `/tools/prototype`. They are not orphans, but one more contextual link each (for example from `/use-cases/edit-figma-with-ai` to the tools pages, and from `/figma-mcp-free-plan` to `/figma-mcp-starter-plan`) would help. Adding a link means writing copy, so it is left to the owner.
2. **`/tutorials` hub.** It does not exist yet. That is S7. When the hub ships, the new tests require it to be in the sitemap and in `llms.txt`, and to have an inbound link.
3. **Second tutorial (S5, in progress in parallel).** The new global tests apply to it too: it must be in `llms.txt`, linked from an indexable page, and have one `h1`, a unique title and description, and alt, width and height on every image.
4. **Optional Twitter tags.** 48 English pages have no `twitter:title`, `twitter:description`, `twitter:image` or `og:locale`. The fallbacks cover this. Add the tags only if a card validator shows a problem; the new test keeps any that are added in step with `og:*`.
5. **Dated descriptions.** Nine meta descriptions include "checked 2026-11-13" (for example `/compare/framelink` and `/figma-mcp-starter-plan`). That is accurate now, but it will look stale in search results. Decide whether to keep the date in the description or move it to the page body only.
6. **`llms.txt` length.** It now lists all 61 sitemap URLs plus `/download`. If a shorter file is preferred for LLM context, move the long-tail pages under "Optional". The coverage test checks only that each URL is present, not which section it is in.
